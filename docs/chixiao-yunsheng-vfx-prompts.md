# 《万象》赤霄、云笙技能特效提示词

每位角色制作一套 2×4 设定板，统一为略俯视三分之四 Minecraft 战斗视角，至少画出起手、结算、收势中最重要的两个姿态。单独输出透明 RGBA 高清硬边分层素材：实体轮廓、亮芯、主题纹样、短尾及断散粒子。以浅草地、深地面、正常战斗缩放验收，地面区域内部留空，持续效果不盖住角色。飞行物提供独立、可编辑的 Blockbench 模型，局部正 Z 朝向飞行方向，2D 层只用于增强刃光、折线、轨迹和收散。保持当前武器和技能判定。

## 赤霄｜朱漆军锋

> 以冷银白刃芯、朱漆红漆边、黯枣红阴影、少量哑金铆片为主。像挥动沉重军刀，先压后断，锻刃高光短促锐利，尾部有阶梯状断角。避免火焰、烟墙和通用几何光圈。斩击与冲刺用不同的轮廓：斩击是一束宽刃，位移是两条窄的平行轨迹。

| 格 | 技能提示词 |
|---|---|
| 1 | **破阵战意**：同一目标脚侧叠出短朱色军刻。叠满时三刻亮出银边，技能消耗时三条向内合拢，溢出细铜屑。 |
| 2 | **不屈锋骨**：低血触发时，贴身升起几片枣红板甲影，外沿冷银亮线，断续朱线从脚侧向后拉开，表现护盾与加速。 |
| 3 | **断岳斩**：沿判定前方 100°扇区展开一记横向重刃，弧心亮银，两端收尖；扫过外沿留断续朱红切痕，敌人体附近仅短闪。 |
| 4 | **追魂踏**：向前冲刺用脚略上方两道朱红压风线，起点打下薄小军刻。按真实路线追踪；折返时用更细的银白双线反向回收。 |
| 5 | **赤霄反锋**：格挡窗口展示面前交错护刃。只有反击成立才沿实际伤害扇区释出一记反向银刃，并有细裂痕。 |
| 6 | **裂阵刀罡**：独立穿透弹体，做成银白分段锻刃、收尖刃口、内嵌朱漆脊线、成对铜扣和切角刃尖。以真实飞行三维向量前进，附亮刃薄影与分离的朱红尾屑，穿透时模型继续向前。 |
| 7 | **破军无回**：落点先亮断续朱红标记，随跃进形成收拢的战旗状垂迹。实际落地才亮出几段岩裂和向上弹开的硬边刃片，中央保留脚步。 |
| 8 | **横刀镇岳**：自身护盾用朱漆护片合围，近身三片刀刻表示待命。每次强化命中只显示一次银红重切，短促断散。 |

## 云笙｜青釉灵契

> 以象牙折纸、透亮薄荷青釉、深竹青影和香槟金丝为主，采用折、系、编、回响四种形变。亮处要清晰但面积小。薄云和尾线只在局部，禁止绿色治疗光球、满地发光圆盘和遮脸云雾。

| 格 | 技能提示词 |
|---|---|
| 1 | **同心回响**：同一名友方两次受助才触发；两瓣象牙契纸往身前合拢成玉色小扣，护盾存在时留下低密度跟随契纹。 |
| 2 | **灵铃共鸣**：触发时从铃下送出细金铃波，命中的友方脚侧分别绽开小圈，青白两层展开并迅速淡出。 |
| 3 | **纸鹤传音**：独立折纸灵鹤模型，具备清楚纸翼、折脊、尾叉、尖喙，胸上点缀青釉和少量金线。沿真实追踪路径转向，2D 短折线和纸屑跟随；送达时化成羽页，受阻时在阻点散开。 |
| 4 | **定契索**：玉白丝芯连接施法者和敌方，旁有短断青线，锁扣沿索的方向合紧；延迟结算时线向目标收束并闪出脚边契扣。 |
| 5 | **回音界标**：固定锚点立一座小玉铃，青釉铃体配铜框、铃舌与象牙垂带；地面断续丝纹标出范围，实际脉冲由中心传到边沿。 |
| 6 | **云梭护行**：跟随角色真实移动，青丝双轨像梭子穿行，收势向受援者合拢，并在有盾者身侧留下折羽护片。 |
| 7 | **众生归宗**：蓄势时象牙纸纹依次向阵心聚拢，音乐感由青白波前与香槟金细边构成；每次真实结算从阵心向外另起一次波纹。 |
| 8 | **灵契同舟**：只在真正获得保护的队友身上立起象牙契页与暖金锁扣，施法者脚边一道开域契印。盾仍存在才保留契页。 |
