# 樱隙前线对局经济复演

第 4 批使用同一套 3v3 参赛席位和实体事件比较改前与候选规则。复演输出策划用 Markdown 和逐笔 JSON。三类角色席位在两队对称设置，守护是预设顺风方，毁灭是预设逆风方。[购物与经济实施票](https://github.com/xOyMoveO/MYRIAD/issues/108) · [顺逆风对照决议](https://github.com/xOyMoveO/MYRIAD/issues/100#issuecomment-7234845985)

## 复跑

准备两份完整发行目录，每份包含各自的 release.json、发行 JAR 和平衡快照。从仓库根目录执行以下命令，将目录替换为该次交付的位置。

```sh
python tools/balance/replay-economy.py \
  --baseline /path/to/baseline-release \
  --candidate /path/to/candidate-release \
  --output /path/to/economy-report
```

改前轨使用 #107 的配对发行，候选轨使用 #108 的配对发行。工具核对两份清单的大小、摘要、源码标识及 JAR 内嵌快照摘要。#107 未导出的追赶系数取其固定源码。击杀和兵线公式还与快照导出的采样点核对。场景默认读取 [economy-cherry-v1.json](../../tools/balance/scenarios/economy-cherry-v1.json)，报告记录场景 SHA-256。

## 固定事件与计算顺序

- 四条全程脚本覆盖均势、纯防守、两轮反打、单边重压。每条在 3、5、8、12、16、20 分钟采样。8:00 另外注入人均累计收入领先 15%／25%／40%、核心等级差 1／2／3，每档配对零击杀、终结三连杀核心和击杀零杀三死同级席位，运行至 16:00。预置收入和经验只用于归因，不计入全程主动收入比例。
- 兵线读樱隙首波与间隔，使用固定的 15 秒到达后死亡，按实体类型和编排次序分发。返泉往返的 ±12 秒和野区往返窗口内缺席。无人完成指定补刀时由敌方非玩家击杀，并按合格附近英雄的实际奖励类别入账。整数资格阈值选择主动获取事件，±15% 改变的是事件数量和对象。
- 野怪由快照中的地图营地与怪物类型绑定。固定时点的尝试要满足刷新、存活与路线脚本，逐笔登记跳过原因。塔赏按固定的一、二阶破塔输入结算。实际樱隙地图只配置中路一阶和三阶，重压脚本的二阶是合成对照。其压力投影把保护系数作用到每波固定攻塔压力，经掉塔后再移动后续侵入开始时点。塔保投影独立于基础报告的固定掉塔输入。
- 工资每 100 刻先统一计算后依次入账。离线席位停止领取工资、塔金和发育收益。改前追赶看在线参赛者。候选继续使用锁定席位及其最后收入、等级，资格化离线助攻份额在原席重连后发放。死亡等待仍保留工资，兵线与野怪机会依脚本及死亡状态判定；塔金仍按在线同队参赛资格发放。
- 购物计划保留 0／3／7／12／16／20 分钟回泉检查点，另在复活时读取泉水位置。补给先结算，按持有、视野互斥和钱包记录入账。属性沿每项逐档取整价格结算，选择目前报价最低的属性，同价按角色脚本偏好；这给出最大点数的可达示例。切入场景双方均用同一规则预配点。前沿按「累计收入减已花补给」穷举五维整数配点，卖掉重配属于预算比较，随后要买到哪点以实际购买轨迹为准。

## 读数

- JSON 的 `trace` 用真实刻计时。每个收益项含基础和修正、到账钱包、累计收入、经验槽和实际等级。实体事件的 `id` 对应收入的 `cause`。离线、额外购买尝试、助攻顺序及复活事件在同时间轴可核对。
- `checkpoints` 保留每人的购点、余金、缺口和下一次实际购买等待。`objectives` 记录塔后、反打后即时快照及其首个计划回泉快照。未到达的购买点和等待填 `null`。`frontierBudget` 关联当前轨 `frontiers` 对应金币预算。前沿的每行是力量、智慧、速度、防御、冷却及余金。前沿口径为预算不变且每一维都不能再增加一点的配置；独立战斗价值留给指定角色及动作的 L3 对照。
- 工资追赶、主动追赶、击杀额外赏金与助攻池、塔保分别按 0／0.5／1／1.5 倍单因子重跑，补刀和野区获取同向取 ±15%。助攻池、工资追赶权重与终局节奏由首轮真人主基准样本校准。复演不预测团战胜率。三级信号是策划试测提醒，真人与服务端证据分别引用。

历史原型反映早期 CHERRY_V1 的单席零击杀口径。本工具从配对快照的实体奖励复演六席脚本，工资、XP、补给和近旁结算按该脚本逐笔记录。[旧原型经济脚本](https://github.com/xOyMoveO/MYRIAD/blob/b97a9e0348c9716ecca7eafa7d85f325a8109eb1/tools/balance-prototype/economy.py)
