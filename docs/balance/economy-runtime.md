# 对局购物与经济结算

现行实现对应 [购物与经济 #108](https://github.com/xOyMoveO/MYRIAD/issues/108) 和 [顺逆风经济决议](https://github.com/xOyMoveO/MYRIAD/issues/100#issuecomment-7234845985)。

| 场景 | 属性点 | 丹药、视野与陷阱 |
| --- | --- | --- |
| 开战后的存活参赛者 | 可按分项报价购买 | 仅在主世界己方泉水 10 格内可买，包含 10 格边界 |
| 正式对局等待复活 | 可按分项报价购买 | 不可购买 |
| 候场、选角准备、已结束及非参赛者 | 不可购买 | 不可购买 |
| 训练 | 允许购买，免金设置仍会推进档位 | 允许购买并沿用免金设置 |

回春丹与回灵丹都是 60 金，存活购买后可立即在背包核对。界枢和商店根据服务端分别下发的资格显示操作状态。联机协议为 34，客户端和服务端须一起更新。

同一次英雄死亡复用战绩去重后的助攻名单。击杀者按原击杀赏金领取。两项助攻池分别按本局锁定名单顺序均分，余数依次补 1。第 4 批试测池额为实际入账 101 金及 51 经验，两个合格席位依次各得 51 金／26 经验和 50 金／25 经验。零人跳过两个池。曾作出合格贡献的掉线席位保留战绩及已分出的份额，同局重连时一次性到账。世界对局检查点保存待领份额，领款收据与玩家钱包、经验一起保存。对局结算或无责重开回大厅时清理该局待领份额。正式金额留到第 5 批选择。

追赶分母来自开局锁定名单。金币比较双方人均累计收入，经验比较敌方平均等级与个人等级。掉线取该席最后一次记录的收入和等级。训练与任一队零席位时沿用基础收益。工资每 100 真实刻向在线参赛者发放，阵亡等待仍发放，同一工资刻先计算全队金额再入账。工资追赶暂沿用 1.0 倍，第 5 批待选。

复活 1–15 级沿用 9–37 秒，16–20 级每级延长 32 真实刻。18 级、19 级、20 级分别为 836、868、900 刻，界面显示 42、44、45 秒。恢复旧检查点时沿用已开始的死亡等待截止刻。

## 复核入口

在 JDK 25 环境分别运行各专项。服务端专项使用合成世界和测试参赛者。

```sh
bash ./gradlew build
bash ./gradlew runGameTestServer -PmyriadGameTests -PgameTestFilter=myriad:match_economy
bash ./gradlew runGameTestServer -PmyriadGameTests -PgameTestFilter=myriad:match_assists
bash ./gradlew runGameTestServer -PmyriadGameTests -PgameTestFilter=myriad:early_remake
```

`match_economy` 对照服务器的购买请求、实际余额和物品、权限包编解码与界枢／商店共用的按钮判断、阵亡期间工资与服务器复活截止刻。`match_assists` 对照钱包、经验、战绩和掉线重连、检查点复读。每次运行单独保留日志与 XML。客户端购买界面的画面以及六人正式对局仍待实机验收。

同输入的采购和经济对照见[离线账本](economy-replay.md)。快照记录购物权限、试测池额、追赶系数和逐级复活时长。第 4 批的账本以固定兵、野、塔事件对照。防御每点 +5 双抗、助攻池额与工资追赶倍率继续留给第 5 批复测。
