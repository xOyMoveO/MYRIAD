## 复跑

使用 JDK 25。从保存了 `42e24d3` 发行配对的基线产物读取 `balance-snapshot.json`。新工作树运行：

```sh
bash ./gradlew build
python tools/fabric/prepare-ci-release.py
mkdir -p build/balance/combat
for fixture in balance_haste balance_damage_support balance_control_supply; do
  rm -f build/reports/fabric-gametest.xml
  bash ./gradlew runGameTestServer -PmyriadGameTests -PgameTestFilter=myriad:"$fixture" \
    >"build/balance/combat/$fixture.log" 2>&1 || exit $?
  cp build/reports/fabric-gametest.xml "build/balance/combat/$fixture.xml"
done
python tools/balance/replay-combat.py \
  --baseline /path/to/42e24d3/balance-snapshot.json \
  --snapshot build/balance/balance-snapshot.json \
  --logs build/balance/combat --output build/balance/combat
```

报告包含两版源提交、快照摘要、固定输入、离线和服务端读数。专项日志和 XML 共同证明匹配和执行结果。落霞与伊珂的零购纵向轨迹继续使用独立回放。实图玩法与体感由玩家验证。三级平衡提醒均可继续保存、构建、试玩、合并和发行，专项实际失败另行记录。
