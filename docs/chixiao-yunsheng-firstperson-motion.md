# 《万象》｜云笙、赤霄的第一人称动作提示词

共用：Minecraft 第一人称，显示自己的方块手臂和袖口，不添加肘段。主手始终握住现有武器，转腕时掌心与握点一起移动；副手空闲时才入画。主要动作留在画面两侧和下沿，镜头和准星不晃动。下文 `CAST` / `HIT` 只标现有服务端事件，不延迟命中、弹体或位移。

## 云笙 · 灵契玉铃

松肩、腕先动，停顿轻短。右手握住铃顶的青玉提环，铃身自然垂在掌下；左手负责托、引、放。铃口的摆动幅度小于战刃挥幅，避免横扫画面。

| 动作 | 第一人称制作提示词 |
| --- | --- |
| 纸鹤传音 | 左掌从左下托起，右腕向前轻送玉铃。`CAST`：掌心沿弹体离手方向打开，双手立即回落，纸鹤飞行期间不重复抬手。 |
| 定契索 | 右手稳铃，左手向前探出后指掌收拢，`CAST`：收掌时系上第一道契索；仅在第二次结算有效时短向后收一下，牵索断开不补动作。 |
| 回音界标 | 选点时左掌低位朝前，右手将铃压在右侧。确认时 `CAST`：左掌向下点落，玉铃跟着短促压低；持续脉冲留在场地中。 |
| 云梭护行 | 选点时左手引路。起跑时铃收向右侧，手腕不晃；`CAST`：在实际停点结算护盾时左手沿左外侧打开，铃轻轻回正。位移被取消且没有结算时直接收势。 |
| 众生归宗 | 两手向下方中心靠拢，随约一秒蓄势缓慢压紧。`CAST`：实际结束蓄势后，铃向右上振一下、左掌向左前舒展；四次持续结算不让手臂反复施法。 |
| 灵契同舟 | 右手把铃提向胸前内侧，左手从下方托护；`CAST`：双手沿下方同时向外打开，随后稳稳降低。 |
| 普攻一 · 前振 | 短短前送右腕，`HIT` 对应灵弹离手，顺势回右下。 |
| 普攻二 · 回铃 | 从外侧向内侧斜抽，`HIT` 对应铃口经过身前；左手无需入镜。 |
| 普攻三 · 提铃 | 手腕由低向上轻振，`HIT` 对应灵弹离手；多留一小段回荡，但只发一枚灵弹。 |

## 赤霄 · 赤霄战刃

大刀靠手臂和腕转带动，移动有惯性，刃口先走。左手只用在护刀、架势和落斩等关键环节。

| 动作 | 第一人称制作提示词 |
| --- | --- |
| 断岳斩 | 从右上压向左下，`CAST` 与既有前方斩击同一事件；刃尖越过画面下半部后自然卸力。 |
| 追魂踏 | 去程将刀压低，刀尖沿冲刺方向领路；有效二段把刀反收近身，两段都在实际停止时回势，不额外补伤害。 |
| 赤霄反锋 | 大刀横架在准星下，空闲左手托近刀背。等实际反击时 `CAST`：由下向外翻刃；没接到攻击只撤架。 |
| 裂阵刀罡 | 右臂从侧下快速斜上甩刀；`CAST` 刀罡飞出后，战刃仍在手里，收在画面右缘。 |
| 破军无回 | 选点时刀留在侧边；起跃后抬刀、空中合势。`CAST`：真正着地结算时双手向下压出重斩，取消则不做落斩。 |
| 横刀镇岳 | 右手横刀并收近身体，左手短暂护在前侧。`CAST` 开启护盾与蓄势后回持刀位；之后强化普攻仍沿三式轮换。 |
| 普攻一 · 压斩 | 右上向左下斜切，`HIT` 以实际接受的近战为准；顺势留在低位。 |
| 普攻二 · 反撩 | 翻腕从左下反撩至右上，刀停在右侧，别把整片刀面拍过去。 |
| 普攻三 · 平扫 | 右侧向左平扫，握刀手略向前伸，刃轨偏低；扫完沿下沿回右侧。 |
