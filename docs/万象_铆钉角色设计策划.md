# 《万象》角色设计策划：铆钉 · 战场筑垒师

## 一、角色定位

**背景：**来自科幻工业世界的重装工程兵，使用冲击锤与墙面锚定器作战。

**战斗定位：**重装战士／保护型前排／地形控制。

**核心玩法：**选择墙面作为战术支点，通过走位、击退、牵引与冲锋改变交战位置，让敌人撞墙，为队友创造进攻或撤退机会。

角色不自动生成墙体，也不会自动吸附敌人。强度主要来自玩家对地形、角度与时机的判断。

两种发展倾向：

- **筑垒守卫：**依托锚点阵地承伤，保护队友。
- **破阵先锋：**主动调整角度进场，将敌人推向墙面。

> 以下数值为基础生命20点环境下的原型值。接入《万象》时需根据现有生命、成长与伤害体系换算，不能直接作为正式数值使用。

## 二、技能选择结构

| 技能类别 | 选择规则 |
|---|---|
| 被动 | 驻地装甲／破阵节拍，二选一 |
| 常规技能 | 固定拥有冲击锤与战术锚点 |
| 主要技能 | 应急撑架／牵引索，二选一 |
| 终极技能 | 固守协议／破城冲击，二选一 |

被动、主要技能与终极技能独立选择，共形成 **8种组合**，不锁定整套流派。各技能等级成长另行设计。

## 三、固定常规技能

### Q｜冲击锤

短暂抬锤后向前挥击，对前方约 **3格**内的敌人造成 **2点伤害**。仅准星附近的首个敌人受到约 **2格水平击退**。

主目标在随后 **0.4秒**内撞到墙面时，额外受到 **1点伤害**并定身 **0.5秒**。

- 冷却：7秒。
- 地面不视为墙面，同次击退仅触发一次撞墙。
- 击退方向由实际施法方向决定，不向锚点自动修正。
- 抬锤具有清晰预兆，敌人可以横向躲避。

**用途：**推开突进者、打断敌方站位，或将敌人推向预先选择的墙面。

### W｜战术锚点

瞄准 **8格内实体方块的侧面**安装锚点，持续 **18秒**，最多存在一个；再次施放替换旧锚点。

Q使敌人撞到锚点周围约 **1.5格**的墙面时，触发“锚击”，将本次撞墙定身提高至 **0.8秒**。

- 冷却：8秒。
- 锚击恢复时间：5秒；恢复期间锚点仍可用于其他技能定位。
- 依附方块被破坏后，锚点消失。
- 锚点进入未加载区块时停用，不主动加载区块。
- 以清晰标识区分“可锚击”和“恢复中”。

**用途：**建立战术支点，明确角色准备争夺或防守的区域。

## 四、被动二选一

### P₁｜驻地装甲

在自身锚点 **4格内**保持接地累计 **2秒**，获得 **2点护盾**。

- 护盾不可叠加。
- 护盾被打破后，至少间隔10秒才能重新获得。
- 离开范围2秒后，剩余护盾消失。
- 可以在范围内走位，不要求站立不动。

**倾向：**围绕阵地持续承伤。

### P₂｜破阵节拍

Q成功造成撞墙后，强化下一次普攻，持续 **4秒**。

强化普攻命中时额外造成 **1点伤害**，并减少E的剩余冷却 **2秒**。

- 触发间隔：5秒。
- 不增加普攻距离。
- 必须实际跟进普攻命中，才能获得完整收益。

**倾向：**撞墙后追击，形成持续进攻循环。

## 五、主要技能二选一

### E₁｜应急撑架

展开持续 **2秒**的防御装置，施放瞬间为自身及 **3格内队友**各提供 **2点护盾**，护盾持续2秒。

- 展开期间，自身受到的击退减少50%。
- 施放时距锚点不超过4格，减少W剩余冷却2秒。
- 同一目标的撑架护盾不叠加，仅保留较高剩余值。
- 冷却：13秒。

**用途：**抵挡爆发、保护队友，也可用于提高进场容错。

### E₂｜牵引索

向自身锚点发射牵引索，将**自己**沿直线拉向锚点，最多移动 **5格**。

- 锚点必须位于10格内、可见且路径有效。
- 遇到实体障碍立即停止，停在墙前。
- 移动期间再次按E可提前松索。
- 不造成伤害，不牵引或控制敌人。
- 冷却：10秒；无有效锚点时施放失败，不消耗冷却。

**用途：**调整推撞角度、返回阵地或撤退。

## 六、终极技能二选一

### R₁｜固守协议

以施放时的锚点位置建立半径 **4格**、持续 **6秒**的防御区域。

- 区域内自身与友方受到的伤害降低15%。
- 自身进入区域时获得一次3点护盾，持续至大招结束。
- 区域内敌人受到Q击退时，击退距离增加25%，不延长撞墙定身。
- 需要10格内有效锚点。
- 冷却：55秒。

区域位置在施放时锁定，之后更换锚点或破坏地形均不移动、取消区域。

**用途：**守通道、保护后排、争夺目标点。

### R₂｜破城冲击

蓄力 **0.7秒**后，向前发动最远 **5格**的重装冲锋。

命中首个敌人后立即停止，对其造成 **4点伤害**并向前击退。敌人撞墙时，额外受到 **1点伤害**并定身 **0.8秒**。

- 若撞在锚点附近且锚击可用，定身提高至1秒，并使锚击进入恢复期。
- 自身碰墙立即停止，不能携带敌人穿墙。
- 蓄力具有明显声光提示，可被横向走位规避。
- 冷却：50秒。

**用途：**抓住站位失误开团，或在敌人突进后反打。

## 七、战斗循环与反制

基本循环为：

**W选择墙面 → 调整站位 → Q推撞 → 跟进普攻或主要技能 → 使用大招控制交战节奏。**

守卫方向通过护盾与区域减伤保护队友；先锋方向通过牵引换位、撞墙强化普攻与冲锋寻找突破。混搭组合分别改变承伤能力、机动能力和开团方式，不应出现某个分支必须绑定另一个分支的情况。

### 八种组合

| 被动＋主要技能＋终极技能 | 主要打法 |
|---|---|
| 驻地装甲＋应急撑架＋固守协议 | 围绕阵地持续保护队友 |
| 驻地装甲＋应急撑架＋破城冲击 | 承伤等待机会，再用冲锋反打 |
| 驻地装甲＋牵引索＋固守协议 | 离开阵地干扰，再牵引返回防守 |
| 驻地装甲＋牵引索＋破城冲击 | 依靠护盾站位，用牵引调整冲锋角度 |
| 破阵节拍＋应急撑架＋固守协议 | 在区域内反复推撞，接强化普攻 |
| 破阵节拍＋应急撑架＋破城冲击 | 用撑架抵挡反击，跟进冲锋与普攻 |
| 破阵节拍＋牵引索＋固守协议 | 在阵地周围主动找侧面推人机会 |
| 破阵节拍＋牵引索＋破城冲击 | 机动开团、推撞追击，容错最低 |

### 敌方反制方式

- 横向移动，避开锤击与冲锋路线。
- 远离锚点墙面，转移交战区域。
- 利用障碍阻断牵引，用前排承接冲锋。
- 退出固守区域，等待效果结束后再进攻。

## 八、统一规则与实现要求

**控制递减：**同一目标受到铆钉的撞墙定身后，3秒内再次受到此类定身，时长减半；同名角色共享递减记录，避免多人连续控制。

### 判定规则

- 服务端统一裁定命中、撞墙、位移与伤害。
- 撞墙依据方块碰撞形状检测侧向障碍，不能将落地误判为撞墙。
- 牵引与冲锋逐段检测路径，不能只检查终点。
- 首版锚点使用位置记录与特效表现，无需放置真实装置方块。
- 死亡、退出、切换维度或更换角色时，清理个人状态及来源效果。
- 护盾、减伤与控制优先接入项目现有接口，明确刷新、吸收和来源清理规则。

## 九、开发顺序与验收重点

1. 完成Q、水平击退和撞墙判定，验证墙角、半砖、台阶。
2. 完成W的安装、替换、失效及锚击恢复机制。
3. 优先实现 **破阵节拍＋牵引索＋破城冲击**，验证地形操作是否有趣。
4. 补齐保护分支，测试全部8种组合及多人交互。

### 试玩清单

- 平地、隧道、柱子、台阶、半砖上的撞墙判定是否符合直觉？
- 锚点的位置、范围与恢复状态是否容易辨认？
- 对手能否通过横向走位躲开Q、R₂？
- 牵引能否可靠停在墙前，松索落点是否可控？
- 方块被破坏或路径中途出现障碍时，位移是否安全停止？
- 全部8种组合能否完成有意义的战斗循环？
- 双铆钉集火时，控制递减和护盾规则是否正常？
- 多人同时使用时，是否出现重复伤害、位置回弹或明显性能下降？

重点记录 **Q撞墙率、牵引后的有效命中率、护盾实际吸收量、最长连续受控时间**。

首轮平衡优先防止窄地图压制、护盾减伤过厚和连续推撞失控，保留“通过站位打出一次有意图的撞墙”这一核心体验。
