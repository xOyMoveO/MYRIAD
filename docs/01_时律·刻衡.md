# 时律·刻衡

日期：2026-11-12｜内部ID：`keheng`｜状态：玩法功能已在开发训练入口实现，服务端证据见[刻衡功能验证记录](verification/roster13-keheng11.md)；正式选角与全阵容适配待 #28，视角和效果按用户要求后置调整。

## 一、角色印象

「不是我变快了，是你的一秒变长了。」

刻衡是使用精密时计刺剑的中近距离时差斗士。外观偏精密奇幻：墨青短外套、金属刻度饰件、腕部擒纵机构，不强制采用修仙长袍。性格冷静、动作简洁，不设计满屏钟表或一身大齿轮。

核心体验：用迟针让敌人的起手变慢，展开局部缓时域，在别人迟缓的动作间穿行；也可以守住狭窄入口，保护后排。伤害来自自己正常节奏的施法，不来自额外加速、暂停全图、复制敌方伤害或倒退生命条。

定位：中近程控制 / 反突进 / 时差消耗。弱点：手短于炮台法师、没有无敌和自动回溯，缓时不等于让攻击消失；被领域外的人集火仍然危险。

基础生命：600，每级+85，20级2215。其余初始属性沿[共同规则](00_总览与共同规则.md)。

普攻：原版近战左键点选，时计刺剑造成基础A物理伤害；不自动扇形、不自带技能伤害。银白细刃光只作短命中反馈，常驻不占满视野。

## 二、什么是「自己不变的时间减慢」

缓时倍率记为 `μ`。`μ=0.60` 表示敌方受影响动作以正常速度的60%推进；同样的起手要用原来的 `1/0.60≈1.67` 倍时间完成。

| 对象/系统 | 是否减慢 | 精确定义 |
|---|---|---|
| 刻衡本人 | 不受自己的缓时影响 | 行走、普攻、施法、弹体、CD均维持正常；不是额外加速，也不免疫敌人其他控制 |
| 友方角色、兵线、友方弹体 | 不受影响 | 不惩罚队友，不改变队伍正常节奏 |
| 首版适配名单内的敌方英雄、小兵、普通野怪 | 部分行动减慢 | 水平自主移动速度×μ；普攻准备/攻击恢复进度按μ推进 |
| 已接入时间接口的敌方技能 | 起手与自主motion减慢 | 只推进尚未完成的起手/位移进度，伤害不提前发生；motion总距离不变、碰撞仍逐步检测 |
| 首版适配角色的敌方技能弹体与原版箭弹 | 在领域内减慢 | 真实弹体轨迹进度×μ；不是只让客户端模型变慢。光束、已经命中的判定不追溯 |
| 实际CD、法力回复、Buff/Debuff时长、DOT及引导跳伤间隔、地面预警 | 不改 | 全部使用真实时间，防止延长灼烧、无限推迟控制结束或用缓时回蓝 |
| 跳跃重力、摔落、击退/击飞、镜头转向 | 不改 | 不悬空、不扯视角，不把敌方强制移动当自主动作减慢 |
| 防御塔、水晶、泉水、大型首领 | 不改时间速度 | 设施不受控制；大型首领保留攻击节奏，合法技能仍可对大型首领造成正常伤害 |
| 世界Tick、其他玩家网络、全局昼夜 | 不改 | 严禁用全服tickrate或客户端假卡顿实现 |

同一对象处于多个缓时效果时只取最小μ，**不相乘**；本角色μ最低0.30。普通移速减速与缓时移动部分取更强者，不叠乘；攻击速度方面也取单一最强时间限制，不重复降低两次。敌人离开区域后，下个服务端tick恢复当前应有速度，没有附送长时间减速。

最终十三名可选角色及非英雄对象的缓时范围见[共同规则](00_总览与共同规则.md)。十名旧版角色在本次交付中删除，不保留不受缓时的旧版可选阵容。所有领域按三维范围和中心遮挡判断，不隔实体墙或楼板生效。

敌方已处于不可阻挡/控制免疫时，不施加角色行动缓时；被减慢的独立敌方弹体仍按弹体规则处理。净化可移除单体迟针缓时，并获得0.75秒该角色缓时免疫，防止站在领域里净化后同tick重新挂上；净化不删除整个领域。迟针基础持续1.25秒按现有韧性规则缩短，μ不变；领域不因目标韧性缩短，净化后的0.75秒免疫固定。此交互属于新控制机制，须在实现时明确接入和测试。

缓时不加倍任何伤害，不降低伤害数值，不让已经判定生效的攻击倒回起手；领域消失时恢复速度，但不把已等待的攻击突然补算多次。

W护盾与被动B护盾按独立来源管理；同一次W放下领域时，人物只有确实在该领域有效范围内才触发被动B。两盾数值都不超过自身生命上限的正常预算，不增加生命上限。

主要A、终极A在合法落点成功布下地面预警后独立完成，不要求施放者站着维持；之后受控既不撤销预警，也不删除已落成领域。主要B依附施放者，眩晕、沉默、击退／击飞等强制位移会打断并清理；外来禁锢仅限制移动，不单独中止随行领域或原地施法。Q命中形成的单体缓时按韧性修正后的真实持续时间到期。死亡、退出、换角、跨维度、重置或关闭玩法统一清理，包括未生效的地面预警。

有效命中包括被护盾吸收的伤害，不包括完全免伤或无敌；同次施法对同目标始终最多计一层，三层清空后也不能由该次施法余下跳伤重新计层。完整控制、空间与计时规则见共同文件。

## 四、玩家容易理解的加点与连招

- 控场路线：P-B5、Q3、W2、主要A7、终极A3，共20点。守入口和掩护队友，伤害不是最高。
- 时差进攻：P-A5、Q3、W2、主要A7、终极B3，共20点。迟针试探 → 迟界限制横移 → 错拍步改角度 → 终刻贯穿。敌人仍可以离开走廊、从领域外打断刻衡。
- 机动追击：可将主要A换为主要B，但控制较弱、作用范围更近；不能同时学习两种主要或两个终极。

进攻路线纸面上界：S230、P5/Q3/W2/主要A7/终极B3，Q231＋迟界291.5＋贯穿840.5＋一次被动155.5＝1518.5减伤前；对魔抗50约1012.3实际伤害。三次主动均须命中同一英雄且在刻痕窗口内，W无伤害、不计刻痕；不含普攻、队友伤害、重放Q或额外隐含倍率。不是瞬间秒杀2215生命目标，也不是实测结论。

反制重点：拉出领域、利用墙体切断贯穿、从领域外消耗、在0.8秒蓄势期控制刻衡。被缓时的危险弹体仍会到达，不能站着当成已经挡下。刻衡对建筑与大型首领没有停时优势。

## 五、武器「恒刻」与生成提示词

### 造型与握持

单手精密刺剑，不是粗重阔剑。主体长而薄的银白针形剑刃，黑曜墨青金属脊线；握柄以深青皮革缠绕，护手是**偏心、开口的半环时计结构**，嵌琥珀微型擒纵轮与一粒青绿时晶。剑格不使用一整块圆钟盘，不放可读数字和巨大钟表。

建议整体长约1.15米，其中剑刃约0.85米、柄和护手约0.30米；模型柄部可握区清楚，结构细但不靠一像素断线承重。刃口朝视野前方，宽面朝侧，不能剑身平拍敌人。第一人称右下低位持握，屏幕中心60%保持通透；仅蓄势时让青绿刻度在护手外围短暂显现。

建议独立拆件：剑刃、剑尖、剑脊、护手外环、内层擒纵轮、时晶、柄、柄尾。可旋转的轮件是模型局部件，不绑定旧全身动作系统。

声音建议：清晰而克制的机械轻扣、细金属颤音、短空气抽吸；领域起势一声低短共鸣，维持只用轻刻度声，结束清晰合拍。不持续播放刺耳秒表高频，也不强制降低其他玩家所有游戏音频速度。

## 七、接入风险与验收

这是需要新增共享能力的角色，不是改几个移速Buff就算完成。建议新增可复用的局部 `ActionTimeScale`、可调起手进度接口和弹体时间倍率接口；角色每个技能仍独立文件，领域只发布来源、对象、μ和真实到期时间。

不能改服务器Tickrate，也不能让客户端相机假慢而服务端继续原速结算。对尚未接入时间接口的技能，开发阶段必须列清单并在说明中标出缺口；不得宣称所有技能已能缓时。首版须完整覆盖已确认十三名角色的普通攻击恢复、可延迟起手、自主motion及受控弹体，同时适配兵线、普通野怪和原版箭弹；十名旧版角色直接删除。已命中的普攻不追溯为起手。

弹体在领域内推进慢，但最大作用距离不增加；采用真实飞行进度寿命＋最多2倍原始真实寿命的安全上限，超时消散不在原地留下模型。已经发出的弹体从领域出来恢复正常，不储存多次攻击到离场瞬间爆发。瞬移不改成慢速传送。

对有重力的箭弹，减慢的是该弹体自己的完整飞行仿真步长，包含其重力/阻力计算，不是只把位置速度乘μ而仍按全速向下坠；角色跳跃/摔落的重力则保持正常。只有已经接入这种局部仿真的弹体才可被正式标记为支持缓时，原版弹体需单独适配和测试。

至少验证：本人/队友不变；相同μ不叠乘；场内外跨越；攻击已准备一半；技能快出手时进圈；motion中途进出圈；坡地/空中弹体；强制位移与重力不受影响；净化/免控；DOT/CD/回蓝真实时间；塔和大型首领免控；死亡/换角清理；多人延迟下模型与伤害一致。
