# 用统一预算比较收益，按证据解释平衡提醒

2026-11-28 确认。固定同阶段参考脆皮的最大生命，以其 1% 为一个强度预算点。固定输入后比较有无某项效果的净差，伤害、有效回复与避免的掉血分别归因。同一角色八套合法终局分支分别核对四项极值。独自出手、队友先控、多目标战斗与推塔保留各自的场景和读数，策划据此判断角色的强项与代价。

L1 静态枚举，L2 检查收入与购买时点，L3 执行逐事件合法连招，L4 以同输入在本地引擎抽检。理论上界写清约束，可达值给出动作和状态，缺输入列出受影响指标。真人体验及其版本单独归档。引擎单段的命中记录只能支持它实际测到的范围。

一级提醒报告确定差异，二级报告与已校准范围或角色契约的偏离，三级报告试测趋势与缺口。全部提醒保留原始人工设值以及保存、构建、试玩、合并和发布的权利。设计例外可用于解释。编译、打包与 GameTest 的实际失败作为技术执行结果如实记录。预算参数、审计输出和四个标杆场景见[实施规格](../balance/implementation-handoff.md#四角色标杆与证据)。
