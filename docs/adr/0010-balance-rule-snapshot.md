# 从游戏的权威定义导出与发行包配对的平衡快照

2026-11-28 确认。每个生效字段只有一个维护位置。易调系数和曲线逐批迁入带 Schema 的数据，命中、出膛、撞墙等条件继续由类型化 Java 结算。尚在 Java 的字段从实际定义导出，服务端、技能介绍卡与离线工具因此可以在相同输入下对照。碰撞、射程和起手等手感参数供分析读取，调整归属原机制。

构建导出名录、字段单位、适用条件、稳定效果标识与覆盖声明。合法零、机制不适用及所需字段缺失分别表达。格式版本约束消费方，源码提交标识出处，规则摘要绑定候选数值方案。生成时间和机器路径不参与规则摘要。发行清单分别记录快照与 JAR 的 SHA-256，使交付双方能验证是否为同一版本的制品。

经济假设、命中率、场景和可选设计例外独立版本化。普通调参冻结场景，机制改变使动作失效时单独升场景版本。现有独立 GameTest 期望保留，便于检查导出、说明和服务端是否一致。两个首批样例和目标构建入口列在[实施规格](../balance/implementation-handoff.md#实施批次)。
