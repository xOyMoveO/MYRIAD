# 在正式开战时锁定地图的兵线和营地节奏

2026-11-26 确认。樱隙前线和其他自建单线地图都可以承载 3v3，同一张图又允许以 1v1、2v2 或 3v3 开战。地图作者显式选择节奏，服务器在正式开战时锁定该版本。这样同一张图上的出门路线和打野时机可以重复练习，编辑地图或有人重连都不会挪动本局的刷新时间。自建旧地图、5v5 和训练预览沿用原值。

专服在对局检查点保存已选节奏版本。兵线及已死亡营地沿用保存的绝对截止时刻，尚未首刷的营地使用本局版本和原始开战时刻。旧检查点缺少版本时按原节奏恢复。以后调整已发布节奏需另设版本，使已开战的旧局能按时打完。裂隙蟹复活倒计时的阵营情报随原计划保留。

六人真人局以开战至水晶摧毁衡量用时。少人局和自动化对局可用于检查路线和规则，另行记录。16–20 分钟是首轮观察区间。
