# 在正式开战时锁定地图的兵线和营地节奏

2026-11-26 确认。樱隙前线和其他自建单线地图都可以承载 3v3，同一张图又允许以 1v1、2v2 或 3v3 开战。地图作者显式选择节奏，服务器在正式开战时锁定该版本。这样同一张图上的出门路线和打野时机可以重复练习，编辑地图或有人重连都不会挪动本局的刷新时间。自建旧地图、5v5 和训练预览沿用原值。

专服在对局检查点保存已选节奏版本。兵线及已死亡营地沿用保存的绝对截止时刻，尚未首刷的营地使用本局版本和原始开战时刻。旧检查点缺少版本时按原节奏恢复。以后调整已发布节奏需另设版本，使已开战的旧局能按时打完。裂隙蟹复活倒计时的阵营情报随原计划保留。

六人真人局以开战至水晶摧毁衡量用时。少人局和自动化对局可用于检查路线和规则，另行记录。16–20 分钟是首轮观察区间。

## 2026-11-28 平衡体系补充

以樱隙前线 `CHERRY_V1` 的 3v3 为唯一主平衡基准。六人真人局从开战至水晶摧毁观察 16–20 分钟节奏，18–20 分钟内常规中位玩家达到 Lv18–20、终局发育可负担 12–16 点属性。目标购买权限为属性点在局内随时可买，补给在存活且处于己方泉水范围内时可买。

5v5 以独立的地图供给倍率适配 22–28 分钟的目标节奏，沿用同一套英雄、属性和购物权限。地图预设与倍率版本在正式开战时锁定并随检查点恢复，历史检查点按原版本解读。1v1／2v2 沿用本图节奏，核对参赛名单、经济算术与重开边界。真人体验、离线场景和引擎专项分别记录。[实施规格](../balance/implementation-handoff.md#场景与报告)


## 樱隙前线候选 V2

地图可显式选择 `cherry_v2`。首波、波次间隔及营地计时沿用 `cherry_v1`。兵线生命与攻击从原首个成长节点起随正式对局时间增长，第 16 分钟追加终局压力并线性进入 20 分钟以后。补刀与附近分成在 0–20 分钟平滑增长并保留整数结算，法兵和攻城兵的基础补刀赏金分别为 40 和 65 金。进行中的 `CHERRY_V1` 续用旧版公式。旧检查点缺少节奏字段时按 `STANDARD` 恢复。样本入口和待验证范围见[战场固定场景](../balance/battlefield-scenarios.md)。
