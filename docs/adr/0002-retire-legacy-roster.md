# 删除十名旧版角色，统一为十三人阵容

用户在2026-11-12需求对齐后明确追加“直接把旧版角色删了”，替代先前保留十名旧版角色并推迟缓时适配的方案。删除离歌、观澜、无相、绯羽、绾月、玄甲、洛衡、沈砺、折川、明烛；最终保留十一名现有新版角色并新增刻衡、伊珂，共十三人。

这意味着放弃十名角色的可玩兼容性，以统一可选阵容和缓时规则；不能只隐藏选角。仍被保留角色调用的公共能力须先解除旧角色依赖，正常非法或已删除角色 ID 输入须被拒绝，不通过自动映射到其他角色掩盖删除，也不授权批量修改正式存档。

2026-11-13 用户明确按“存档不存在任何玩家在使用老角色”实施，替代此前针对退役玩家状态的兼容假设。取消 #4 的历史状态兼容、重新选角保护、存档／检查点降级及仅为此新增的效果来源恢复；不集成其实现。代价是本轮不支持上述历史数据情景。删除正式入口、正常输入合法性校验、有效角色保存恢复，以及普通游戏内死亡／换角／退出等生命周期清理仍在范围内。本决策不代表十名退役角色已删除。
