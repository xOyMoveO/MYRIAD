# 纯无手第一人称共用姿态计算，武器各自定义轨迹

万象用一套运动学计算处理本地玩家的纯无手第一人称姿态。长剑与重锤可以共用挥砍算法，弓弦与箭尾可以有自己的约束。共用边界止于一帧可供绘制的姿态，服务端继续决定出手、命中与伤害，第三人称继续使用各角色已有的表现入口。三种标杆先以 Java 定义参数，调参需要重新构建客户端。经实机验证后再确定哪些字段适合推广到其余武器。[架构工单](https://github.com/xOyMoveO/MYRIAD/issues/78)

## 从武器定义到一帧姿态

武器用右主手声明模型握点、待机姿态、主轴和刃面方向。近战轨迹另给出挥砍平面的正交基、带方向的扫角、各阶段时长与普攻接触窗口。相机坐标取右为 +X、上为 +Y、前为 −Z。肩侧隐含支点带动握点绕弧移动，腕部绕真实握点翻刃。大弧由显式扫角采样，单位四元数用于组合旋转和混合姿态，保留作者指定的挥砍方向。输出左主手时统一关于矢状面镜像一次。平移的 X 取反，旋转按分量顺序 `(w,x,y,z)` 映为 `(w,x,−y,−z)`。伴生件、刃尖和特效锚点遵循同一变换。

| 合成顺序 | 输入与职责 |
| --- | --- |
| 1. 待机 | 将模型握点放入相机空间的待机姿态，纳入装备抬手与副手持物避让。副手非空物品沿用原版绘制。 |
| 2. 主动动作 | 一件武器同一时刻由一个主动作驱动握柄。轨迹用归一化阶段进度求位移与转角，蓄势渐缓、爆发加速。接招从当前求得的位姿及线速度、角速度过渡到新轨迹。主动期锁定装备抬手高度。 |
| 3. 接触与后坐 | 可靠命中在接触窗口内降速武器轨迹并叠加微振。弓按确认放箭产生前释回弹。过冲可用欠阻尼弹簧，归位与打断残差用临界阻尼收敛。 |
| 4. 程序化微动态 | 按重量叠加呼吸、移步、转头滞后与起落惯性。自定义武器接管原版重复摇晃。按动作阶段平滑衰减各通道，并遵守原版视角摇晃设置。 |

二阶弹簧以当前偏移、速度、目标、固有频率、阻尼比及本帧经过的秒数求出新偏移与速度，采用与帧率无关的解析步进。动作衔接保留平移与旋转残差，旋转残差在局部轴角空间中衰减后再与目标四元数组合。手感时长与微动态掩码遵循已定的构图与重量分级。[统一构图、坐标系与微动态决议](https://github.com/xOyMoveO/MYRIAD/issues/77)

同一渲染帧只推进一次状态。主副手、弓弦或刀鞘、贴刃特效和镜头从同一份只读结果取得所需握柄位姿、附着点或镜头反馈量。镜头强度为零时，武器仍完整运动。绘制入口的先后和被调用次数均不改变弹簧、连段或顿挫进度。

## 同步与时间

客户端沿用已有输入和姿态接收入口，在 `client/firstperson/` 内将与本人武器有关的信号交给对应轨迹。普攻实际提交时可以本地起手，预输入仅进入微蓄姿态。以下消息各自保留原有语义。

| 来源 | 第一人称使用方式 |
| --- | --- |
| `WeaponPosePayload` | 动作、起始时刻、进度及倍率用于定位当前动作相位。已同步的局部行动倍率只应用一次。 |
| `ShuoViewPayload` | 依动作、令牌与开始时刻区分朔的收拔刀、各段斩击和取消。刀鞘与刀身共享握柄帧，再解算鞘口约束。 |
| `LuoxiaBowPosePayload` | 本地可先搭箭。拉距跟随服务端给出的蓄力工作量，满弓表现取自对应阶段与蓄力进度。仅确认放箭触发前释回弹，提前松手、取消及已过期令牌各循原语义。 |
| `AbilityVfxPayload` | 按角色和事件含义读取。专属普攻接触可以证明发生过接触，只有能进一步归属本次动作时才可触发其顿挫。通用特效、伤害飘字与限频打击音都不足以认定某刀命中。 |

缓时作用于已有同步支持的行动进度。武器局部顿挫只改变该武器轨迹的视觉采样进度，持续时间按未暂停的表现时间计。准星、转头随动和服务端行动继续独立推进。游戏真正暂停时冻结表现时钟，恢复首帧从冻结处继续；切角色、换世界或死亡则清除主动作、残差、弹簧和待处理回执。[局部行动进度 ADR](0001-local-action-time.md)

## 接触窗口与原型验证

轨迹经过普攻接触姿态（HIT）时，挥空也会走完整弧面。对已可靠归属当前一刀的回执，早到则暂存至窗口开启，窗口内到达则当帧触发，窗口关闭或动作被接替后丢弃。一刀最多一次完整顿挫。归属不明时顺势挥完，迟到的回执不能转给下一刀。

- **天刑**用三段斩验证跨屏弧面、翻刃和收招打断。现有普通挥剑缺少可逐刀归属的确认，需区分真实触发的顿挫与只能验证的挥砍轨迹。
- **铆钉**用横扫与重砸验证重量、回弹，以及锤头和火花同帧同位。专属普攻接触消息缺少逐刀序号，连击时须记录归属不明而跳过顿挫的情况。
- **落霞**用同一帧验证弦与箭尾贴合，分别观察提前松弦、满弓稳持和确认放箭。放箭后的前释回弹以释放为准，箭在远处碰撞不会再次驱动握柄。
