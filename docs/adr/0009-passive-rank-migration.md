# 按可核实的旧局点数返还被动投入

旧版通过普通技能点提升被动，存档保存各项阶数和余额，缺少逐笔消费记录。新版由已选分支和英雄等级推导被动阶数，因此只有能确认来自旧正式局、角色分支和阶数合法、普通点数收支相符的记录，才可按原手动被动阶数一次性退款。训练存档沿用训练点数规则。

例如 7 级玩家已在主动技能花 3 点、被动 A 花 2 点、余额 2 点，合计正好 7 点。迁移后余额为 4 点，A 自动到三阶。退款后的余额最多等于当前等级预算减去其他已花的普通点数。余额、分支和迁移版本一起保存，重复恢复仍得到相同结果。

来源不明、互斥分支同时有投入或点数对不上时，记录原因并保留该局进度，到新局启用新规则。登录时的常规补点同样遵守这一决定，以免把无法核实的旧投入间接发回。
