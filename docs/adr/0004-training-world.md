# 同一服务器用独立世界承载训练场

主地图正在比赛时，未参赛玩家仍需要练习。训练场因此设在同一台服务器的独立世界，供未进入正式对局的玩家随时前往，练习完成后可回到大厅。

现有训练开关作用于整台服务器。训练场的施法、冷却、金币和地图实体应限于练习玩家及训练世界；同服比赛继续使用正式对局规则。开局、结算及战场清理也应限于该场对局，以便训练者能够练完当前动作。

训练期间保留队列顺位与等待时间，照常显示少人提议及退队入口。名单锁定时离开练习场并进入选角；练习获得的等级、金币和个人开关不带入正式对局。

训练场提供近战假人区、标距射道和位移障碍区。训练者可在个人菜单换角、创建人偶、恢复生命、刷新冷却或开启无冷却模式。PvP 默认为关闭，双方都主动开启后可以对练，任一方关闭即可结束切磋。
