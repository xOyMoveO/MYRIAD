# 万象｜寒泽与青萝第一人称动作提示词

共用：Minecraft 第一人称，取玩家自身皮肤的方块手臂与袖口。主手掌心始终卡在杖柄握点，副手没有持物时参与引导，左利手把主、副手方向对调。动作集中在视野下方与两侧，不摇镜头、不遮挡准星。用 `AIM` 表示选择落点，`HOLD` 表示真实蓄力，`CAST` 表示服务端确认弹体出发、护盾生效或阵地布下。持续地形效果不重复驱动手臂。取消选点或打断蓄力就收手，不播放释放。素材沿用霜脊晶杖和碧露莲枝杖，不绘制替代武器。

## 寒泽｜短促、硬朗；像切开冰面

| 动作 | 生成提示词 |
| --- | --- |
| 冰锥术 | 主手把晶杖抵在右下，空手指向前。每发冰锥实际出手时将杖前点一下，副手跟着做一个短促截停。三发依次由低到高再压回，间隔跟随出膛，中途不做整套重复挥舞。 |
| 霜盾 | 杖从外侧往身前架起，副手做一次向内挡的动作。护盾生效时两手急停，短停后沿原路放下。是防住一击，不是打出去。 |
| 绝对零度 | 选点时副手低位锁住落点；确认后把杖牵向身前，双手逐步合拢，在原有一秒蓄力里稳定下压。结算抬杖后短促沉腕，与冰刺升起同拍。 |
| 裂冰长棱 | 肘往后收，杖身降低且指向前方；发射时沿直线送杖，副手打开保持平衡；短促回弹后回到低位。是出膛，不是挥剑斩。 |
| 千里冰封 | 选点时副手平伸贴着下沿找范围，确认时向外沿低位扫过一段宽弧，把冰域铺出去；之后的周期冰刺只在世界里播放。 |
| 玄冬壁垒 | 双手在下方收成窄门，杖较竖直；生效时向两侧猛撑，像把防线顶起来，随后缓缓放下。 |
| 普攻一 · 短点 | 主手微收后用杖尖快速向前点出，立刻止动。 |
| 普攻二 · 横拨 | 晶杖在下方往外带，出膛后短横拨，保持准星净空。 |
| 普攻三 · 沉扣 | 杖尖略抬，出膛时短压腕，带更明显的沉手收势。 |

## 青萝｜圆润、松弛；像引露、抽丝、展叶

| 动作 | 生成提示词 |
| --- | --- |
| 青藤玉露 | 主手稳持枝杖，副手掌心向上，轻托后沿小弧线递向队友；没有锁定队友时，副手向内将露水捧回自己。 |
| 缚生藤 | 主手用枝杖细小上挑，副手从身侧向前翻腕。藤种离手那一拍两手同向领出，继而柔和回落。 |
| 护心丹阵 | 选点时空手掌心朝下悬在视野边缘；确认时沿落点轻轻按下，枝杖留在外侧，之后不随护盾脉冲反复按手。 |
| 千丝渡厄 | 副手从身前向前送出再回勾，表现丝线接上后收住张力；目标回退为自己时改成近身绕回。持续连线不锁住手臂。 |
| 万木春晖 | 选点时枝杖偏低，副手在下方找落点；确认后掌心翻上并沿弧线抬起，像把新芽托起来。后续治疗脉冲只在地面出现。 |
| 悬壶天幕 | 两手从身前相合再向两边展开，空手翻掌，杖随主手画出更饱满的外弧。结束时仍握住杖柄，不向上抬镜头。 |
| 普攻一 · 掬露 | 副手从低位轻托向前，主手只让杖尖略作响应。 |
| 普攻二 · 横拨 | 副手从外缘沿小弧线拨向前方，杖向另一侧平衡。 |
| 普攻三 · 翻芽 | 副手在身前翻掌向前上方托出，枝杖随腕稍挑，整体缓收。 |

普攻是已有的右键法术弹。三套姿态随成功发射轮换，停顿较久后从第一套开始；它们不改变发射位置、攻速或伤害。
