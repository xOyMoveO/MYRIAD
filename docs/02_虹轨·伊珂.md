# 虹轨·伊珂

日期：2026-11-12｜内部ID：`yike`｜状态：需求已对齐，未实装。

## 一、角色印象

「阵列展开。下一发，请不要站在那里。」

伊珂是一位把法术当成精密炮击使用的远程法师：平时携带收拢的魔导炮杖，进入主技能姿态后，杖头护瓣展开、聚焦环前移，玩家本人变成远程火力阵地。不是现代步枪手，也不是自动召唤炮塔角色。

外观建议：深紫短披肩、浅色内衬、少量珊瑚红/黄铜阵列组件，轮廓轻巧，器械比人物肩宽略大但不把全身吞进装甲里。武器看起来有重量和机械接合，弹药由魔法凝聚，不使用弹壳和实弹匣。

定位：远程持续魔法输出 / 阵地压制 / 预判炮击。优点是架炮后的射程和连续火力；缺点是站位暴露、转移慢、没有位移或无敌，不能一边高速跑一边享有最强炮台输出。

基础生命：550，每级+75，20级1975。其余初始属性沿[共同规则](00_总览与共同规则.md)。普通姿态左键发射普攻，右键不额外发射；普通攻击射程10格、速度26格/秒，发出小型暖白魔导弹，命中首个敌人造成A物理伤害；普攻不消耗法力、不享受架炮的Q强化、不产生法术刻印。

## 二、炮台玩法的具体边界

- 普通姿态仍能走位释放Q/W；主技能A以定身换26格炮击，主技能B以较低伤害和20格射程换缓慢移动。
- 炮台**手动开火**：按Q或在其冷却结束后再次按Q，每次按下只发一炮。初版不做长按自动连射，不自动找人，不替玩家瞄准。
- 架炮时普攻不可用，左键不会绕过炮击间隔额外开火；每发Q仍消耗法力，空炮也耗弹、耗蓝。不能因为进入姿态绕过资源限制。
- 架炮每次最多5发（主要A）或4发（主要B），持续最多6秒，不随攻速/冷却增加弹量。再次按主要键可结束，走完时限、弹量耗尽、法力不足、施放终极或受硬控均退出。手动退出不发末炮、不退CD。
- 只有从主要技能成功展开后才进入架炮。进入和退出不刷新原Q冷却；本轮架炮第一炮需要原Q已转好；后续用独立最短炮击间隔。退出后Q剩余CD取“退出时原剩余值”与“最后一炮对应的当前等级完整Q冷却”较大者，不能瞬切姿态连发两炮。未发过炮则不凭空新增Q冷却。
- 转向不拽玩家镜头。准星照常响应鼠标，独立炮口瞄准标记以最多90°/秒追随；射击用服务端认可的炮口方向，只有炮口标记接近准星时才是准直射击。需要掉头时应先转炮，而不是伪造镜头减速。
- 架炮是姿态，不是全程蓄力读条。每一发有独立0.25秒短起手/亮线提示，出膛才扣该炮蓝与弹数；开始短起手后被打断不补发。主要技能完成0.45／0.35秒展开时才扣主要费用并启动CD，展开前被打断不收费；姿态时限从展开成功开始计。

普通Q在出膛时提交该发蓝耗与冷却，未出膛取消不收费、不新增冷却。Q短起手允许50%正常速度移动。W确认合法落点并布下预警时付费、启动CD；其0.55秒恢复阶段限制为50%正常速度并暂停下一炮至少0.55秒，不要求持续引导，随后受控不撤销已布下预警。上述移动许可均不解除主要A定身。主要技能展开及两种终极蓄势／引导均定身，不能用小跳绕过；终极在确认合法施放、开始蓄势时付费并启动CD，之后中断不退款。所有提交点重新校验资源，被动的“成功施放”也以这些提交点为准。

沿用可配置技能键与地面选点流程。按主要技能键退出姿态，终极B再次按终极键取消；未完成起手不缓存连点，恢复可用后需重新按键。详细时点见共同规则。

以上姿态最短间隔是炮击独立时间，不是给Q额外充能；冷却属性仍正常缩短原Q和主要技能CD，但不增加每次架炮最多可发的炮数。主要技能CD从展开成功开始计算。普通伤害和减速不退出架炮；眩晕、沉默、击退／击飞等强制位移会打断未完成起手并退出姿态或终极引导。外来禁锢只禁止移动，仍可原地施法，不单独打断炮台或光束。

Q普通形态弹在终点引爆，所有判定只由服务端进行；装饰尾流不能多算伤害。眩晕／沉默／强制位移，或死亡／换角等会取消未出膛的炮；已经合法发出的弹体不因施放者单纯受控凭空消失，但死亡、换角、退出、跨维度、重置或关闭玩法时，统一清理未生效预警、弹体、姿态、计数、模型状态和循环音效，不遗留伤害。

有效命中包括被护盾吸收的伤害，不包括完全免伤或无敌；同次施法对同目标始终最多计一层，三层清空后余下跳伤不能重新计层。缓时可减慢伊珂未完成的起手和独立弹体，但姿态6秒上限、炮击间隔、地面预警和已开始引导的光束跳伤仍按真实时间。例：μ=0.5时Q起手变为0.5秒，炮击间隔不变。

范围伤害按三维距离与爆炸／区域中心遮挡判定，墙体和楼板可阻断；不要求施放者在效果发生时仍能看见目标。光束与弹体仍按各自实际轨迹碰撞，不能靠装饰穿墙结算。

## 四、输出节奏与反制

推荐架炮路线：P-A3、Q5、W2、主要A7、终极A3，共20点。先用普通Q试探 → 找侧翼位置、开主要A → 手动连发5炮 → 退出/耗尽后用终极压走位。W留给逼近者，不能既安全后撤又保持最强26格姿态。

自保路线可把P-A换P-B；需要转移则将主要A换主要B。终极B适合队友提供控制时持续扫射，但自身定身、转向有限，不能拿它当瞬发自动锁定光束。

纸面长窗口上界：S230、P3/Q5/W2/主要A7/终极A3；普通Q面板293.5，架炮每炮234.8，5炮共1174；同一英雄连续5炮再中终极，可触发2次被动，每次106；重轰684.5。总计2070.5减伤前，对魔抗50约1380.3实际伤害，约为2000生命的69%。共需70＋5×35＋160＝405法力；至少包含约5秒连续暴露射击，再加重轰蓄势与飞行，并要求所有预判均命中。不含W、普攻、额外Q或队友控制伤害，不能拿此数值当瞬间爆发。

终极B满级S230：每跳167.5，6跳1005减伤前，魔抗50约670实际；被动在整次束流里至多记1层，不能每跳触发一次附加伤害。

反制重点：看到定轨展开就换角度或绕近身，利用墙遮挡束流、分散站位，逼伊珂在放弃阵地和继续暴露之间选择。远界重轰至少1秒可见预警，没有跨全图自动锁头。伊珂无位移、无击退和硬控；35蓝一炮意味着不能无成本持续压制。

## 五、武器「虹列」与生成提示词

### 造型与握持

一把能从携行状态展开为炮击状态的**魔导炮杖**。下部是有明确单手握区的深紫长柄，上部是偏长的三瓣聚焦框架，暖白细晶位于中心；黄铜/淡金机械环围绕法术发射轴，珊瑚红护瓣与紫罗兰内衬形成清楚层次。炮口要有深度、镂空和真实结构，不是把一块发光宝石放在粗木杖上。

整体建议约1.25米。携行时宽约0.20米，架炮时三瓣向外展开至约0.65米；长而有方向感，不是肥短大方筒。无枪械扳机、弹匣、弹壳、现代瞄准镜；这是法术聚焦器，不是沈砺的枪械换皮。

第一人称携行低位放右下，架炮时只有炮杖后部/手掌在边缘，炮口聚焦环应位于视野外侧或前下方，不在准星前堆满闪光。手贴握区、不显示肘关节；第三人称清楚看到三瓣展开和前向炮口，实际开火方向不能与模型朝向相反。

建议拆件：握柄、配重尾、后部支架、核心细晶、独立聚焦环、三片可展开护瓣、导轨、端部小饰片。模型局部展开有自己的状态，不恢复旧全局骨骼动画。
