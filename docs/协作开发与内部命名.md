| 用途 | 当前名称 | 说明 |
|---|---|---|
| 对外中文名 / 英文名 | 万象 / MYRIAD | 原名仙凡劫，角色题材不再限于修仙 |
| 模组 ID / 资源命名空间 | `myriad` | 2026-11-12 按用户要求完成身份迁移 |

| 游戏命令前缀 | `/myriad` | NBT、系统属性和测试前缀也使用 `myriad` |

本次不是显示名称修改，而是破坏兼容的内部身份迁移：旧版本的物品、实体、存档键、地图设施 JSON、HUD 设置和网络命名不会自动继承。不要同时加载新旧两个版本。先备份旧世界，在新世界测试，并同步更新客户端和服务端；如需沿用旧世界，必须另行实现并验收数据迁移。

## 构建与运行

当前为 Minecraft **26.2**、NeoForge **26.2.0.59**、Java **25**，Gradle Wrapper 为 **9.7.0**。推荐安装 JDK 25，再用 IDE 打开仓库根目录，导入 Gradle 工程。

Windows PowerShell，在仓库根目录执行：

```powershell
java -version
.\gradlew.bat build
.\gradlew.bat runClient
```

产物在 `build/libs/`。Linux/macOS 使用 `bash ./gradlew build`。首次构建需联网下载 Gradle、NeoForge 和 Minecraft 依赖；没有缓存时不要加 `--offline`。Java 工具链解析可能为辅助任务另行下载所需 JDK。

修改新版角色、技能、位移或相关表现后运行专项：

```powershell
.\gradlew.bat runFirstGroupTestServer
```

提交前也可执行 `python tools/check_namespace.py --jar build/libs/myriad-0.1.0.jar`，检查源码命名空间、JSON 和发行包中的旧标识残留。2026-11-12 此项审计、构建和两轮新版角色聚合专项已通过；尚未进行迁移后的客户端画面和旧世界迁移验收。

测试报告在 `build/reports/first-group-gametest.xml`。专项通过不代表所有旧角色、全量测试、客户端观感或平衡已经通过验收。`runArenaTestServer` 目前依赖原作者机器上的外部地图 fixture；源码仓库不含该存档，不能在新电脑直接当成可运行的通用测试。

`一键编译并导入Minecraft.bat` 和部分美术/音频工具仍含原作者机器路径；它们不是新电脑的通用入口。请优先使用上面的 Wrapper 命令，手动将构建包安装到自己的测试实例。不要直接执行自动覆盖其他人正式实例的脚本。

## 源码入口

以下路径相对 `src/main/java/com/myriad/`：

| 修改内容 | 主要入口 |
|---|---|
| 角色 ID 与旧版角色定义 | `character/CharacterType.java` |
| 新版技能登记、分支、加点校验 | `character/rework/FirstGroupSkills.java` |
| 新版角色数值与金币五属性 | `character/rework/FirstGroupGrowth.java`、`player/LevelSystem.java` |
| 每个角色的具体技能 | `character/skills/<角色ID>/`，已重做角色通常在 `rework/`；朔直接在 `shuo/` |
| 施法、选点与位移共用层 | `character/ability/AbilityRuntime.java`、`AbilityTargeting.java`、`client/DashController.java` |
| 普攻、伤害与护盾 | `combat/BasicAttackSystem.java`、`DamageCalc.java`、`player/ModShieldSystem.java` |
| 玩家状态与同步 | `player/PlayerData.java`、`PlayerDataProvider.java`、`network/NetworkSetup.java` |
| 对局、地图设施与兵线 | `game/GameManager.java`、`MatchArena.java`、`LaneSystem.java` |
| GUI / HUD | `client/gui/`、`client/HudOverlay.java` |
| 第一人称兵器与手臂 | `client/firstperson/`，如 `ShuoView`、`ShuoRig`、`ShuoMotion` |
| 朔的技能、位移与贴刃特效 | `character/skills/shuo/ShuoSkillVfx.java`、`ShuoDashVfx.java`、`ShuoVisuals.java` |
| 游戏内回归检查 | `game/*Checks.java`，主要由专项测试聚合运行 |

技能定义资源位于 `src/main/resources/data/myriad/role_rework/`，含 `first_group.json`、`second_group.json`、`shuo.json`。修改简介时同时核对实际技能类与客户端浮窗，而不是只改 JSON。

`FirstGroupSkills` 是历史类名，当前已登记第一组、第二组与朔，共 11 名新版角色；不应按类名误判它只管理五个人。其余角色仍有旧实现。旧技能类存在不代表当前选角实际调用它。

## 协作边界

- 服务端权威处理伤害、蓝耗、CD、目标合法性和 motion；客户端输入、HUD 与特效不能替代服务端校验。
- 每角色、每技能独立实现，共用层提供基础能力；不要把具体机制堆到批次注册器里。
- 新版力量用于普攻，智慧用于技能强度。符石系统已删除，旧存档清理不能误恢复系统。
- 历史全局动作系统已移除；当前部分角色的第一人称手臂/武器是独立实现，不要为修持刀恢复整套旧动作系统。
- 新版技能分支与旧技能结构并存，先追踪实际绑定再修改；避免只改未使用的历史类。
- 每次玩法、平衡、界面或视觉更新写玩家看得懂的更新日志，并说明构建、安装、专项验证与实机验收的区别。
- 原作者 `AGENTS.md` 中的本机安装路径只适用于原作者机器，其他开发者不得照搬覆盖自己的正式游戏。
- 建议每项修改建独立分支，提交源码和必要资源，不提交 `.gradle`、`build`、`run*`、游戏存档、令牌或账号信息。

## 资源、地图和授权

`src/main/resources` 含构建所需的现成游戏资源，`art`、`art_source`、`scripts`、`tools` 保留工程内已有的素材与辅助工具。部分工具的原始输入位于工程外的 `role_assets`、个人下载目录或其他本机路径；这些外部文件不是运行构建的依赖，重新制作素材时可能需要作者另行提供。仓库不含 3v3/5v5 世界存档或完整游戏实例。

素材来源与许可见 `src/main/resources/META-INF/licenses/`。项目当前声明 `All Rights Reserved`，公开源码不等于重新授权所有第三方素材，也未自动变更为开源许可证。发布再分发包前应核对各素材原许可。

原策划文档位于作者本机 `E:/mod/策划文件`，不属于 Gradle 构建输入；其中旧方案与当前实现可能不同。协作时以本文件、源码和明确选取的开发记录为入口，不将旧策划当成全部已实装。
