## 实际环境与边界

MC 26.3、Fabric Loader 0.20.1、Fabric API 0.166.2+26.3、Java 25。复用共享资源 `~/.local/share/minecraft/assets`，启动前5149项完整性校验通过，没有整套重下。主逻辑使用 integration 合并后的代码；客户端第二次启动已加载本轮最终资源修补。

从零生成的合成配置运行于隔离 `run-fabric-server/`，独立服务器端口25644。实际账号为 `MyriadPilot`、`MyriadObserver`，后增加第三个真实进程 `MyriadLate`。各进程独立目录与认证桥接，没有以同进程 fixture 玩家或模拟玩家替代真实物理客户端。

队伍和角色选择、修行学习、技能键、地面确认/取消、普攻及结算界面均走生产客户端入口；原生输入经过26.3 SDL键盘/鼠标处理函数。服务器夹具命令仅负责位置、经验及提高合法攻击/防御值以缩短攻塔；未直接写对局阶段或设施伤后生命值。两模式均按现有源码允许的实际人数开局，没有另加满员6/10人条件。

## 失败、停止范围与收尾

快速连续GUI点击曾未触发学习，后调整操作间隔并实际读回；没有将未学习写成成功。两模式攻塔期间都真实发生塔击死亡/观战等待，保留了未推进和重试；后续提高夹具防御、自然复活后继续完成，未改塔/水晶生命。结果不代表平衡或正常属性下的竞技整局。
