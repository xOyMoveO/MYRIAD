## 原始失败与处理

- [首次独立服务器重启日志](evidence/arena-starting-failure-20261116.txt)：`SERVER_STARTING` 恢复调用 `LaneSystem.restore` 时世界为空，且3v3关闭灵脉访问了尚未创建的玩家列表。已修复实际生命周期入口，后续两模式分进程恢复通过。
- [验收runner顺序失败](evidence/arena-runner-order-failure-20261116.txt)：测试mod自己的 STARTED 断言可能抢在主mod恢复监听器之前。runner改为首个END_SERVER_TICK，待所有世界就绪监听器完成；不据此修改玩法状态。
- [重新分队原始失败](evidence/arena-rejoin-team-failure-20261116.txt)：五人模式重新加入的部分身份被pending reset覆盖阵营，手动开始被错误拒绝。修复后同样5v5→3v3→5v5输入通过。
- 初轮fixture还发现默认管理员权限为0、泉水只在整秒tick执行、空模板缺乏基地到线路的地面支撑。分别通过显式测试OP、在生产脉冲时点检查和合成平面补齐fixture；没有关闭原断言或改变这些玩法规则。

Minecraft/Fabric可能在异常结束时仍让Gradle显示 `BUILD SUCCESSFUL`；因此本报告同时使用日志中的实际GameTest完成信息和结构化报告 `passed`，不以Gradle状态代替结果。GameTest XML若为空套件，单独保留并说明，不能写成XML提供了完整case证据。
