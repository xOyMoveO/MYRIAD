# Triage Labels

工程技能使用以下五个标准角色；本仓库的 GitHub 标签与角色同名。

| 标准角色 | 仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求已明确，可交给代理执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 不予实施 |

技能提到分流角色时，使用本表“仓库标签”列。调整标签词汇时，修改该列并同步 GitHub 中的标签。
