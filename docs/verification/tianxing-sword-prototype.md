# 天刑·雷纹长剑标杆原型

本原型验证纯无手第一人称的待机、三段普攻及收剑。首轮录像中，第三刀扫过假人胸前时剑刃几乎缩成一条线，收剑却斜穿准星。第二轮将主挥砍与回收分开设计，按正常攻速观察两刀之间约 1.4 秒的完整过程。[标杆原型一：天刑·雷纹长剑无手第一人称待机与挥砍手感验证](https://github.com/xOyMoveO/MYRIAD/issues/79)

## 构图与轨迹

- **待机与转头。** 在 70° FOV 下，参考原版持剑将雷纹长剑安放于右下竖直前指位：握柄微露上段，锋刃朝前、刃面呈 3/4 侧向展示，待机纵深角约 `+27.5°`（测试区间 `+25°` 至 `+35°`），屏幕投影保持接近竖直，不斜切也不横放。转头时剑身稍落后于视角，回稳期间保留准星周围的视野。
- **第一刀与接招。** 斜劈后留下低位余势，普通攻速冷却期间逐渐换侧预备。单击停手时沿单段连续低弧自然回到待机，连续点按时从上一刀的收势接入。
- **第二刀。** 握柄经左侧低位进入反手斜劈，蓄势时与相机保持距离。斩过目标后，右下视野应能同时看到护手和至少半截剑身。左主手对称。
- **第三刀与收势。** 横扫带 10° 至 15° 微斜，收窄两端扫角，中段应看清刃面和贴刃刀光。左侧低位余势顺接第三刀末端切向，消除左端绕剑轴翻转；左右两侧收剑均改为单段连续贝塞尔低弧回位，沿画面下缘绕过准星与假人面部且中段不停顿。

> 注：下方历史实机对照影片录制于首轮与第二轮原型；第三轮待机竖直前指、单段连续收剑与第三刀左端去翻转调整已在真实 Fabric 26.3 客户端由玩家实机确认。

## 左主手与命中反馈

**天刑的左主手采用纯几何镜像。** 默认左下 HUD 可以遮住部分护手和握柄，右侧副手火把沿用原版位置。希望看全握柄的玩家可以调整个人 HUD 布局。这个取舍适用于天刑标杆。

**本轮评估构图与动作轨迹。** 低速余势在挥空时也会出现。训练假人扣血回执可验证一次普攻实际生效；天刑表现层仍缺少能归属到具体一刀的生产回执，命中瞬间的局部顿挫和主观打击感另行验证。
