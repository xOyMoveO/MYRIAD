# C 键技能图标悬停验收

2026-11-26 在 Minecraft 26.3、Fabric Loader 0.20.1 的独立合成测试服验收。两个真实客户端通过大厅排队、少人开局和选角进入 1v1 对局。两端客户端、测试服和本地交付 JAR 的 SHA256 均为 `cab4d61c5a06fc9a566fe781c1948c8bfe44d3b022485e0ed75c58bbe07c2047`。

| 场景 | 实际观察 |
| --- | --- |
| 正式对局，中文，960×540 逻辑尺寸 | 夜影学习一级「影杀」后，图标悬停显示蓝耗 70、冷却 9 秒、减速 25%、基础持续 1.5 秒、射程 15 格，以及敌方风墙可拦截。 |
| 同一技能，320×180 | 滚动后将鼠标移出图标，卡片消失，已选「影杀」、技能点不足和升级按钮继续显示。 |
| 鼠标命中与滚动 | 实测图标、分支角标、技能名、浮层、空白与滚动边界。在裁剪边缘上下分别取点，仅视口内的图标像素触发。点击卡片覆盖的另一技能格，可以选中底下的技能。 |
| 学习操作 | 双击被动后服务端确认学到一级，继续升级至满级后仍可查看。同组另一分支可预览，确认时点数保持原值。Tab 定位候选、Enter 选中、再定位确认并按 Enter，服务端确认学到「回影」。 |
| 等级与费用 | 训练免蓝、训练无冷却能同时显示。铆钉「战术锚点」零投入显示基础可用、强化 0/5、8 秒冷却。普通未学习技能显示一级预览，被动省略费用。 |
| 形态与二段 | 夜影施放「回影」后打开技能页，卡片显示免费回返和正在倒数的窗口，窗口到期后恢复通常用法。伊珂进入定轨炮台后，「虹轨弹」改为显示下次炮击时间和剩余炮弹。朔的「鞘返」按当前收鞘形态展示。 |
| 缩放、语言与换角 | 复查 960×540、427×240、320×180；含英文牵引索及其中的自有锚点可见、路径须容身限制。换角后旧选中项和滚动位置清空。真实客户端分别用中文和英文读取全部 120 个候选的卡片数据；切换法语后「鞘返」正确回退至英文。 |
| 相邻界面 | 属性图标、补给仍显示原提示。H 大厅能进入角色图鉴并打开详细介绍；关闭后战斗 HUD 正常显示。结束操作时两端的持有输入数均为 0。 |

本地执行 `bash ./gradlew --offline build`、`python tools/check_namespace.py --jar build/libs/myriad-0.1.0.jar` 和 `bash ./gradlew --offline runGameTestServer -PmyriadGameTests -PgameTestFilter=myriad:training_ui`。构建和审计成功，GameTest 1/1 通过，其中技能页覆盖 108 组布局、可见图标命中与双语资源，另验证共用浮层的滚动边界。截图保留实机原始像素，视觉偏好待人工确认。
