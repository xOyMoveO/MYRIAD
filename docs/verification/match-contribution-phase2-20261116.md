## 一、已接入规则

- 死亡前160真实tick内（含第160tick），对该敌人造成实际生命/护盾伤害、施加实际控制，或有效治疗/护盾保护了与其交战的队友，均可参与。多个命中或多种贡献合并为一次助攻；重复事件、零伤害、零治疗、空盾不会增加次数。
- 保护关联的“参战队友”必须与该敌人有最近160tick的真实伤害或控制交互。辅助行为本身不会制造新的交战链，不能通过治疗另一个治疗者无限传递助攻。
- 击杀者继续取得原有金币、经验与赏金。新增奖池为 `floor(击杀金币/2)`；合格助攻者各获 `floor(奖池/人数)`，零头不发，不重复乘1.4金币换算。没有助攻者不发奖池，不从击杀者扣钱。
- 奖励进入现有 `addGold`，纳入第一阶段的累计金币与逆风口径。每次实际死亡/击杀各有按生命周期的结算保护；复活结束重新开启下一条生命，保存恢复不会重复发钱。
- 助攻者须仍在线、保留原队伍和角色，并与目标位于同一维度；在线但已阵亡的参战者仍可取得自己的有效助攻。离线者不分配或补发助攻金币。普通重连不清空仍在窗口内的记录，换角清除旧参与资格。

## 二、统计口径

| 数据 | 口径 |
|---|---|
| 对英雄伤害 | 对敌方玩家的实际生命损失加模组护盾实际吸收，不混入小兵、野怪或建筑 |
| 有效队友治疗 | 服务端治疗完成后实际增加的生命；不含过量、自疗、药品及自然回复 |
| 队友护盾挡伤 | 按真正被消耗的来源层归属施放者；不计发盾量、到期/清除值及自己的护盾 |
| 有效控制时长 | 逐真实tick观察仍生效的控制；解控、到期、目标死亡/移除后停止，不预记名义时长 |
| 对建筑/小兵/野怪伤害 | 各独立生命池实际差值，建筑包含塔与水晶 |
| 补刀/野怪击杀/拆塔 | 实际最后击杀者；同一实体计一次，不改变原有奖励或攻击合法性 |

控制时长对同一目标的重叠部分只归属一个来源：眩晕、禁锢、铆钉强制推行、缓时、普通减速依次优先；同级按强度，再按稳定来源键确定。多个目标可以分别累计，不代表限制了实际技能叠加。眩晕/禁锢观察真实buff，减速观察真实属性修饰符，铆钉观察推行/墙控租约，刻衡观察当前实际生效的缓时来源；此阶段不新增控制效果或改变持续时间。未启用的历史角色技能不恢复或冒充已经适配。

护盾来源显式记录施放时角色、队伍及角色世代，不从技能ID字符串猜施放者。铆钉不叠加的撑架家族只给当前有效层记一次挡伤；同时扣掉隐藏层的对应量，不给每个施放者重复计算同一次伤害。换角后，即使回到同一个角色，旧盾也不能复活旧归因。未知/旧式无施放者接口仍可正常挡伤，但不虚构其辅助贡献。

伤害Pre/Post配对保存扣血前生命，避免死亡处理立即进入复活等待后，将超额击杀伤害错误算入输出、承伤和飘字；不改实际伤害或护盾消耗。既有30秒HUD窗口保持，不把本阶段统计变成死亡回顾。
