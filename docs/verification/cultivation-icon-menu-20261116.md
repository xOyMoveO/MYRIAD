# 角色修行图标菜单与细条读条验证

日期：2026-11-16。分支 `feat/cultivation-icon-menu-20261116`，基点 `fe95e20`。本记录区分静态检查、服务端回归与实际客户端观察，不把未完成项目记作通过。

## 实现范围

- 左侧三个图标切换技能、五属性与补给；技能按被动、主要、常规、终极分为四行，每行两个候选。
- 单击选择后使用统一加点按钮，双击直接加一点；保留技能点、互斥、等级门槛及服务端购买校验。
- 完整说明移至悬停浮窗，按字体测量确定宽度，优先放在第二候选右侧，空间不足时转左；浮窗独立顶层并支持滚动。
- 五属性改用图标；补给继续显示名称和价格。
- 保留原画完整金玉花纹、四角及剑徽，标题避开装饰；面板最多 300 GUI 像素宽，支持小窗口四行同屏，关闭钮为 16 像素。
- 短于 8 tick（0.4 秒）的起手隐藏；其余施法与回城共用 3 GUI 像素细条。输入限制及服务端规则保持。

## 构建与服务端验证

- JDK 25、Minecraft 26.2、正式发行构建使用 NeoForge 26.2.0.59。
- 最终 Gradle 构建及定向隔离运行的 `myriad:first_group`、`myriad:combat_regression` 通过：退出 0，16 秒，两项各 1/1。定向测试启动配置仅用于本地验证；没有修改或关闭断言。
- 菜单专项实际通过 96 个响应式滚动状态、1536 个浮窗边界状态、四行图标和五属性图标可达、单击/双击契约检查；覆盖剑徽与标题、底框与操作按钮避让，以及短浮窗宽度和长浮窗右侧锚定。
- 纯几何和输入状态检查不运行实际 Minecraft 字体及鼠标事件链，客户端观察另记如下。

## MCPFabric 客户端验证

- 仅使用 MCPFabric 及项目原生输入适配，测试世界来自本轮新建 GameTest fixture 副本，未打开正式用户世界。共享资源的 5059 个对象已逐项校验大小和 SHA1，无缺失或损坏，没有整套重新下载。
- MCPFabric 要求 NeoForge 26.2.0.88，因此测试项目与 `.59` 发行构建分离。两者 1200 个生产源文件逐项 SHA256 完全一致；截图不是对 `.59` 发行二进制的直接运行。
- 物理帧 2560×1440；自动缩放（有效 6 倍）为 GUI 427×240，另测 4 倍缩放 GUI 640×360。两种尺寸均实际查看完整原画、四行图标、等级和关闭钮；原尺度长说明可用 PageDown 滚动，4 倍尺度全文同屏。
- 强防重案例：朔 4 级、藏锋 2 级、剩余 2 点；两次原生点击间隔 149ms 后，仅变为藏锋 3 级、剩余 1 点。第 4 级当时仍合法，排除点数不足或等级门槛掩盖第二次消费的情况。重开菜单后，单击维持 3 级/1 点，独立加点按钮才变为 4 级/0 点。
- 无限金币关闭时，力量图标单击不扣费，确认后金币 1000→820、购买等级变为 1；购买回春丹后金币 820→760，背包从无该物品变为 `myriad:blood_pill×1`。
- 一剑开天通过原生 R 释放，24 帧 GPU 连拍中实际查看了剩余 0.7 秒的新细条；原生 B 触发 8 秒回城，12 帧中实际查看了剩余 6.0 秒的同款细条，完成后移动到合法测试支点。
- 验收后通过原版设置恢复自动缩放，读回 GUI 427×240；释放输入为 0 并停止移动，保存退出后读回标题画面、`inWorld=false / serverPresent=false`，再结束本轮测试客户端。

## 限制与保留的失败

- 短于 8 tick 的隐藏仅核对源码和离线绘制，没有单独短起手原生连拍；320×180 由布局专项覆盖，不是本次实机尺寸。多人、缓时进度与全面玩法/平衡不在本轮实机结论中。
- 长浮窗会临时覆盖底部局部操作区域，移出后可操作；这是过程复核中已接受的边界。
- 初轮未筛选 `runGameTestServer`，同服运行 11 项时有 5 项失败：外部竞技场函数缺失、兵线生成、朔命中、铆钉重连和正式选角。随后定向独立公共回归通过；未筛选全套运行不记作通过。
- 紧凑版一次新版聚合在既有天刑断言 `First pierced hero retains the 12-tick root on tick 11` 失败，菜单检查当轮已通过。未改角色源码或断言，全新隔离世界复核和最终版本均通过；不声称该偶发失败的根因已修复。
- 当前构建脚本保留控制提示专项任务名，但本检出没有对应 fixture、注册函数或检查类，未记为已通过的验证项。
