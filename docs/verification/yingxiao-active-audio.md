# 夜影六个主动技能音效

2026-11-26，Minecraft 26.3 / Fabric，联机协议 28。六套技能共 17 条独立 Ogg Vorbis，均为单声道、48 kHz。项目用本地程序合成薄刃、布料、气流与盾膜，全程没有输入录音或外部模型服务。生成器可通过环境变量 `FFMPEG` 指向含 libvorbis 编码器的 FFmpeg。[生成器](../../tools/audio/generate_yingxiao.py) · [音频来源与许可](../../src/main/resources/META-INF/licenses/yingxiao-sources.txt)

## 分轨与事件

下表短名同时表示对应文件 `assets/myriad/sounds/skill/yingxiao/<短名>.ogg` 和事件 `myriad:yingxiao_<短名>`。每条事件都有中英字幕。

| 技能 | 短名 | 时长 | 服务端触发条件和听众 |
|---|---|---:|---|
| 影杀 | throw | 218 ms | 创建飞匕后在弹道起点播放 |
| 影杀 | hit | 166 ms | 首个目标实际损失生命或护盾，在弹道接触点播放 |
| 影杀 | block | 152 ms | 飞匕被敌方风墙截住，在交点播放 |
| 化影 | enter | 328 ms | 隐身效果生效，仅本人 |
| 化影 | exit | 191 ms | 该次隐身实际消失，仅本人；死亡、离场等清理跳过 |
| 影袭 | dash | 286 ms | 首步通过碰撞检查、服务端发出位移时播放 |
| 影袭 | contact | 129 ms | 路径有效命中，同次施放三刻内最多一次 |
| 回影 | out | 246 ms | 第一段实际开始位移 |
| 回影 | return_vanish | 169 ms | 成功回返后，发给出发时能看见夜影和出发点的人 |
| 回影 | return_arrive | 158 ms | 成功抵达后，发给此时能看见夜影和落点的人 |
| 绝影追击 | windup | 804 ms | 锁定后从施法者位置开始，按行动倍率播放；结束、打断或丢失施法者视野时按本次施放停声 |
| 绝影追击 | blink | 154 ms | 安全闪身成功后在落点播放 |
| 绝影追击 | stab | 202 ms | 前刺造成有效命中时播放一次 |
| 绝影追击 | cancel | 161 ms | 引导被打断，或结算时目标、落点失效，仅本人 |
| 灵盾 | shield_open | 377 ms | 灵盾实际增加护盾值 |
| 灵盾 | absorb | 141 ms | 夜影本次灵盾的盾层实际吸收伤害，三刻内最多一次 |
| 灵盾 | shield_break | 210 ms | 受击耗尽该盾层，优先于吸收声；正常到期和清理时静默 |

空间音效逐个听众检查距离、战场视野和遮挡。专属命中声接管对应的通用命中反馈。回影第一段仍沿用原有命中反馈，第二段仅有离开和抵达声。

## 验证

- 离线构建成功。在独立测试世界运行 `myriad:first_group`，聚合 GameTest 通过。它包含夜影的释放、护盾、位移、绝影追击等检查。
- 资源审计解码 133/133 条仓库音频，17 条新增音效均核对了字幕、注册记录、Vorbis 声道与采样率，以及发行 JAR 中的文件字节。解码峰值 −3.40 至 −2.69 dBFS；每条最后 5 ms 的峰值均低于 −63 dBFS。
- 独立服务器加两个真实客户端，使用同一发行 JAR，在合成训练世界切磋。场景准备使用测试命令，技能按键和选点使用客户端原生输入。记录客户端 SoundManager 提交与停止事件。
- 施法者、对手和服务器加载的 JAR 的 SHA-256 均为 `b4434d4831fe34ce78d20574be5773c4963625fa9305763c73ed6cc24f6435c7`。双端记录覆盖 27 个场景，17 种夜影声音均观察到 SoundManager 返回 `STARTED`。录得以下对照。

| 场景 | 施法者 | 对手 |
|---|---|---|
| 影杀射空 / 命中 / 风墙 | 只听脱手 / 脱手和点刺 / 脱手和拦截 | 同左，命中时没有额外通用受伤声 |
| 化影自然到期 / 施法破隐 / 普攻破隐 | 入隐与显形各一次 | 无入隐或显形声 |
| 化影中受伤 / 切世界 | 受伤后仍等到隐身到期才显形；切世界只记录此前的入隐声 | 无入隐或显形声 |
| 影袭首步撞墙 / 穿过两个目标 | 撞墙无起步或接触声；多人命中时各一声起步、接触 | 同左。对手生命从 1665 降到 1600.17，另一目标从 500 降到 406 |
| 回影正常 / 只有出发端可见 | 两端各一声 | 正常回返听见两端；墙挡住抵达点时只听见离开 |
| 回影落点无效 / 禁锢 / 窗口过期 | 无成功回返声 | 同左 |
| 绝影追击成功 / 目标超距 / 遮挡 | 成功依次蓄势、停声、闪身、刺中；失败仅蓄势、停声、取消 | 成功同左；失败只收到蓄势和停声 |
| 绝影追击眩晕 / 半速引导后眩晕 | 普通引导第 6 个客户端 tick 观察到停声；半速引导以 0.5 音高开始，第 20 个客户端 tick 观察到停声 | 两次都收到停声，均无闪身、刺中和取消声 |
| 灵盾开盾 / 吸收 / 耗尽 / 到期 | 依次验证开盾、吸收、破盾；破盾并扣血时只听见破盾；自然到期静默 | 同左 |

两端退出时均确认 `heldInputs=0`。旧开发测试世界一轮聚合检查曾在焚诀的连续伤害计数处失败，随后在独立合成测试世界重跑通过。尚待人工在实际混音中试听刀刃质感、团战辨识度及音量舒适度。
