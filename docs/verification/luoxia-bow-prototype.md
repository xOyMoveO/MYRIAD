# 落霞·归霞弓标杆原型

归霞弓的第一人称原型覆盖低位斜持、搭箭、拉弦、满弓稳持、确认放箭和取消。实机视频使用右主手、空副手及固定训练场机位。旧版与原型都学习一级「凝霞满弓」与「霞沉一线」。档案录屏中的落霞没有学习这两个候选，旧版同条件对照使用档案 JAR 重新录制。[归霞弓标杆工单](https://github.com/xOyMoveO/MYRIAD/issues/81)

## 弓身、弦扣与箭尾

握柄留在主手侧。随搭箭抬弓，弓身过渡到相应箭种的瞄准倾角。用原模型中对应的顶点在四档弓形间连续插值，使弓臂弯曲和弦扣后移一起发生。每帧计算一次弓形和弦扣，箭尾直接取该弦扣的位置。左右主手各自绘制时，箭仍朝同一远端瞄点收敛。

拉弦进度取本人已同步的蓄力工作量，前段较快，越接近满弓越慢。满弓时，弦扣上方的金紫小镶口亮起并脉冲一次，随后转为稳持亮度；箭尾随弦轻微颤动。本人第一人称用此提示承接原来反复挡住中央目标的就绪花纹，原有的放箭瞬时闪光及技能锁向预警照常呈现。确认放箭后撤下搭箭，握点前挫、轻点头，弦回弹并衰减；约 6.4 游戏刻回到待机。提前松弦与取消只收弓。锁定箭在锁向后继续使用服务端给出的世界方向，即使玩家转动视角也保持原箭道。
