# 樱隙前线裂隙蟹与首波兵线实机记录

从蟹岛斜向射一箭后松手，基线把落霞持续推走 **11.06 格**，整个观察窗口都没有起手。修复后，蟹停在离玩家身体 **0.541 格**的位置，起手后第 **11 tick** 命中，玩家在命中前的水平位移为 **0 格**。相同操作在平整测试场也得到同样的变化。正面和背靠墙站位在基线便能命中。[蟹岛斜角并排录像](evidence/cherry-crab-diagonal.mp4)

蟹岛斜角基线从世界 tick 2227 建立仇恨，直到观察结束均未结算伤害。候选从 1237 建立仇恨，1245 停步起手，1256 落钳，受击前后落霞生命为 575 与 523.276。当时两实体中心相距 4.819 格，有视线。平地相同斜向的实际朝向为 −135°，正面为 −180°。侧前方画面由第二位真实客户端拍摄。

并排视频以服务器首次建立仇恨为零点，左侧基线，右侧修复后。以观察者各帧的世界 tick 取最邻近原帧，覆盖 −0.75 至 +5.00 秒，原帧与对应时点最大相差 2 tick。H.264，1920×640，20 fps，116 帧，5.80 秒。原素材的采样间隔约为 3 tick。

在无仇恨、未发起攻击的蟹身边，落霞保持对角线向前 17 tick 后松键。基线在松键后的 33 tick 内被推离中心 1.010 格，新版同期沿原方向再滑入 0.138 格后停下。双方生命均保持不变。这组试验单独观测静止实体的互推。

## 壳体受击

组合包在蟹岛保留 7600 点模组生命的全新蟹体上逐项复测。英雄站在蟹中心偏侧，沿壳边射击、点击或释放已学技能。原版箭由装有一支普通箭的发射器发射。以下数值取裂隙蟹的服务端模组生命。

| 入口 | 生命变化 |
| --- | ---: |
| 赤霄初始武器，鼠标左键近战普攻 | 7600 → 7565.901 |
| 落霞归霞弓，真实左键拉放 | 7600 → 7546.809 |
| 原版发射器普通箭 | 7600 → 7597 |
| 赤霄一级断岳斩，通过角色面板加点，按 Q 施放 | 7600 → 7547.873 |

切换赤霄后立即进行的第一次普通攻击未扣血。同一角色、站位与瞄点等待两秒，原生左键普攻成功命中，首条记录和复测均已保留。
