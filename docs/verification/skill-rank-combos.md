# 主要技能链的新旧规则对照

以主线 `713b0f5` 为旧版，使用[成长迁移表](skill-rank-growth.md)逐项计算。每次都从 1 级开始合法投点。伤害为单个英雄减伤前数值，护盾为实际可授予的两种来源之和。以下为条件明确的公式对照，未计暴击、减伤及双方走位。

每级普通点优先投入已开放的大招。旧版从 2 级起尽量把被动加到新版对应阶数。余点依次用于解锁第二项主动、点满第一项、点满第二项，再补其他主动。新版的同一被动免费获得。表内配点顺序为被动／第一项／第二项／R，未参与连招的剩余点投给其他主动。

| 角色 | 前两项主动 | 短链条件 | 全中或完整授予条件 |

| 落霞 | 雁过霞痕、一点残阳 | Q 箭命中，下一箭兑现标记，一次普攻；已学 R 计一轮命中 | 同样前缀，R 三轮各中一次。已选凝霞满弓时普攻拉满；旧版 1 级仍为普通箭 |
