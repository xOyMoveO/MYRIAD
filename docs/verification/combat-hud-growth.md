# 普攻、个人战斗 HUD 与属性 V1 验证

测试环境为 Minecraft 26.3、Fabric Loader 0.20.1、Fabric API 0.166.2+26.3 与 Java 25。两个真实客户端使用本地合成训练场，按键和鼠标经过原生输入，命中以受击端的新状态核对。

## 普攻

| 出手路径 | 实施范围 |
| --- | --- |
| 原版近战 | 精确选中优先，包括原本瞄中的不可攻击实体。满蓄力且使用初始武器时，擦边才会发起服务端请求。服务端从眼位按角色原版交互距离重新选择，通过原版攻击回调结算一次。 |
| 伊珂左键 | 每个飞行步先检查原 0.12 格半径，再检查各轴容错。 |
| 落霞普通、速射和满弓 | 三种普攻箭在飞行中保留原 0.09 格半径，并逐轴比较容错。共用飞行类的技能箭使用原技能判定。 |
| 墨尘、寒泽、青萝、云笙的右键魔法弹 | 现有局部查询与中心距离判定已覆盖最大容错。保留原有命中尺寸与风墙优先级，方块碰撞限制本步可命中的距离，贴墙出膛也检查遮挡。 |

辅助以实体原尺寸为基准，每面最多扩张该轴的 15%，封顶 0.30 格，建筑沿用原有判定。弹体先处理当前步已有的基准命中。辅助目标仍须在原射程内，且从段起点到原始实体盒的接触点能够通过遮挡检查。

双客户端对练使用夜影攻击天刑，固定距离和朝向，两次出手之间至少等待 34 个攻击端客户端 tick，再从受击端的新状态判断扣血。下表偏移量从目标原盒的边缘向外量。0% 组由服务器设置 JVM 参数 `-Dmyriad.basicAttackAssistFraction=0`。两组各取 30 次的对照使用开发期间的两个构建；它们的夜影近战和天刑受击代码相同。

| 准星位置 | 0% 命中 / 出手 | 15% 命中 / 出手 |
| --- | ---: | ---: |
| 目标中央 | 30 / 30 | 30 / 30 |
| 盒外 0.08 格 | 0 / 30 | 30 / 30 |
| 盒外 0.10 格 | 0 / 30 | 0 / 30 |
| 隔墙 | 0 / 3 | 0 / 3 |
| 只有一方同意切磋 | 0 / 3 | 0 / 3 |

英雄贴着小兵时，直瞄英雄的一击使其生命从 660 降至 616.71，小兵仍为 95。直瞄小兵的一击使其生命从 95 降至 25.48，英雄仍为 660。此处测的是固定位置的命中边界；移动目标跟手性和玩家对误打的主观感受仍需试玩。

## 战斗面板

[1920 × 1080，完整面板](assets/combat-hud-growth/full.png) · [854 × 480，小窗布局](assets/combat-hud-growth/compact.png) · [854 × 480，展开长聊天时的冷却](assets/combat-hud-growth/compact-chat.png)。三张均为协议 25 最终 JAR 的原始游戏截图，GUI 缩放为 2。

血条、盾量、法力、经验、普攻恢复、四个主动槽和只读被动合并到同一块面板。默认左下，按 GUI 像素给中央原版快捷栏和副手槽留出空间。拖动、缩放、显隐和重置都对整块生效。迁移旧设置时小地图和目标栏沿用各自原有坐标。聊天历史过长时，聚焦聊天显示较少的行，当前页的文字、点击和向上滚动使用同一个范围。

技能槽读取角色实际绑定的按键；未绑定时显示槽位。尚有充能的技能可以释放，下一层恢复单列显示。剩余二段时间与技能冷却分开。训练无限蓝显示满条和 ∞，护盾接在血条末端，文字显示完整盾量。材料见[概念图和 17 项图集切片](../../art_source/combat_hud/README.md)。

## 属性与赤霄

开局 500 金可买一项属性，余额 140 金。五项独立报价，从 360 金开始，每次按前一档的 120% 四舍五入。同一项第 5 点累计 2678 金，第 10 点累计 9339 金。旧点数和余额原样读回，训练免金也推进报价。GameTest 检查了取消旧上限、20 点急速对应 60% 冷却缩减、极高报价拒绝扣款和实际技能描述。

一级断岳斩在零防目标上的减伤前伤害为 93，加一点力量为 100.5，加一点智慧仍为 93。每级技能额外增加 22 点伤害。

固定一级赤霄与一级断岳斩，在 24 物防的合成霜兔目标上测三次蓄满的站地普攻加一次 Q。配对使用相同随机种子，关闭暴击并保留空被动。六组连招各用 69 tick。

| 购买点数 | 三次普攻加 Q 的总扣血 |
| --- | ---: |
| 0 | 235.328 |
| 1 力量 | 278.375 |
| 1 智慧 | 235.328 |
| 3 力量 | 364.469 |
| 4 力量、1 智慧 | 407.516 |
| 5 力量 | 450.563 |

首组野怪对照使用两组相同的霜兔、暮狐和侦察机。在合成场地按同样节奏原地攻击，各从 500 金钱包实际花 360 金。1 力量用 31 次普攻、6 次 Q，耗时 911 tick（45.55 秒）。1 智慧用 36 次普攻、6 次 Q，耗时 1056 tick（52.80 秒）。两组相差 145 tick（7.25 秒），正式地图的走位、拉野和对抗节奏仍需玩家试玩。

### 后续技能的 V1 试调口径

本轮试点是赤霄「断岳斩」。后续新增或重做的普攻型常规技能、大招，可分别从 50%、80% 已购额外物攻起测。施法型常规技能、大招的参考值为 60%、100% 已购额外技能强度，指定治疗、护盾的参考值为 40%、50%。属性来源与伤害类型独立，多段倍率按一次施法对单个目标的总量拆分。已继承普攻物攻的强化攻击只算一次。

对明确标记成长的硬控，每点智慧可增加基础时长的 1.5%，延长量封顶基础时长的 15% 和 0.20 秒中的较小值。四舍五入到最近服务器 tick 后仍须满足上限，再应用原有韧性与重复控制规则。断岳斩只造成伤害，本轮其他角色的控制、治疗和护盾仍沿用各自技能公式。

整块缩放、显隐、拖动和重置均已实测。854×480 窗口中，面板锚点从 (0, 1) 拖到 (0.2248, 0.6333)。松手后位置写盘，退出编辑器后面板使用新位置，「重置当前」将锚点恢复为 (0, 1)。拖动测试通过独立客户端的原生鼠标事件入口完成；宿主未授予桌面鼠标事件权限，测试适配器在派发期间提供窗口焦点并随即恢复。

## 验收范围

在真实客户端，满血 815/815 时实测仍能读到独立的 +352 护盾。夜影「回影」第一段位移后，技能格显示 2.7 秒二段窗口，第二次施放回到起点。最终小窗展开长聊天时仍显示 656/760 生命、629/700 法力和技能冷却；上滚聊天历史时保持可读。

15 个 GameTest 专项分别取得具名 XML 和通过日志：`training_ui`、`melee_arc`、`melee_assist`、`projectile_basic_assist`、`yike`、`luoxia`、`world_time`、`keheng`、`hero_action_time`、`combat_feedback`、`match_economy`、`roster_a`、`first_group`、`chixiao_opening_pace`、`rivet`。远程飞行另跑一次 0% 对照。独立 3v3 合成服务器另通过 34 项训练场检查，覆盖训练参与者、正式对局、练习钱包、单向及双向切磋、撤回和假人归属。

对着可挖方块擦过玩家时，两人同意切磋才接管点击。只有一方同意、撤回同意、对着别人的普通假人时，都实测可以挖掉后方方块。擦过自己的练习假人会保留方块并走普攻。

### 仍需实际对局确认

双客户端固定站位测到了擦边阈值，远程移动目标由服务器飞行步进专项覆盖。真人走位时的跟手感、正式地图清野节奏和对局平衡仍待试玩。满级、技能充能、控制切换等状态由布局及技能状态检查覆盖，本轮没有逐角色录制所有组合，也未测量面板开启与关闭时的帧耗时差值。

## 构建与复跑

发行主包 `myriad-0.1.0.jar` 为 35,366,109 字节，SHA256 为 `7d7509ba06acfa7b448e70fcde02b4acaafa7e2bbed5755013e442ba6b7e57f3`。客户端与服务端需同时更新到协议 25。

```sh
bash ./gradlew --offline build
python tools/check_namespace.py --jar build/libs/myriad-0.1.0.jar
bash ./gradlew --offline runGameTestServer -PmyriadGameTests -PgameTestFilter=myriad:training_ui
bash ./gradlew --offline runGameTestServer -PmyriadGameTests -PgameTestFilter=myriad:melee_assist
bash ./gradlew --offline runGameTestServer -PmyriadGameTests -PgameTestFilter=myriad:projectile_basic_assist
bash ./gradlew --offline runGameTestServer -PmyriadGameTests -PgameTestFilter=myriad:first_group
bash ./gradlew --offline runGameTestServer -PmyriadGameTests -PgameTestFilter=myriad:chixiao_opening_pace
```

各专项单独启动 JVM。以服务器日志中实际匹配并通过的测试和本次 XML 为准。[测试客户端与原生输入](../../tools/mcpfabric/README.md)。
