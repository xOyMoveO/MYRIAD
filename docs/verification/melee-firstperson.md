# 近战普攻的第一人称动作

右主手的构图与接触姿态如下。左主手沿画面中线镜像。握点随手运动，模型围绕实际握柄转动。无手臂客户端只显示持物与特效。

| 夜影 | 右下反握短匕 | 第一段收腕，第二段抬高，第三段绕掌换正握 | 前刺、下砸、从右向左短划 | 刺尖续送，下砸压低，短划掠至左下 | 前刺沿原轴撤回，末段贴下缘翻回反握 |

## 联测

在训练场对自建假人分别测试单击停手、恢复前最后两刻内点按、完全恢复后立即点按。查看左右主手、空副手和持物副手。朔另测收鞘空挥、命中拔刀后停手、右键回鞘，以及抽刀过程中回鞘。

直接攻击沿用即时判定。HIT 标在本地提交后首个游戏刻内，实际录到的渲染帧取决于帧率。输入缓冲先做抬手准备，恢复时重新检查准星。服务端原生攻击受理和训练假人扣血可由独立测试适配记录，分别核对每次出手与实际目标。角色被动附伤依据原有规则结算。
