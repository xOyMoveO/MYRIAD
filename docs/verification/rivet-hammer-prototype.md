# 铆钉·冲击锤标杆原型

本原型用于比较冲击锤的待机构图、重器的支点与沉降，以及已经确认命中时的锤身与镜头反馈。实机对照采用右主手、空副手、70° FOV 和固定训练场机位。三段动作依次是横扫、反向回扫和重砸，均由原有普攻输入触发。[标杆原型二的设计问题](https://github.com/xOyMoveO/MYRIAD/issues/80)

## 握点与重心

握点位于模型坐标 `(0, 5.5, 0)`。画外肩侧支点带动握点绕弧移动，锤柄再绕腕部翻转，使实际打击面领向挥动方向。锤头两端形状不同，接触火花采用打击面中心 `(-10, 23, 0)`。前两击在普通攻速冷却期间保留换侧守势。第三击将锤头从高位压至下方，击面越过目标后仍有下沉与回弹。

## 接触与镜头

铆钉专属的本人普攻接触反馈携带服务端时刻。当前出手的反馈若提前到达，先等到轨迹的接触窗口开启。窗口内首次可靠匹配会使本人武器时间轴以 10% 的速度推进 75 毫秒，并使锤面微振。重复、过期或前后两次出手均可能归属的反馈予以丢弃。挥空按相同轨迹走完余势。该消息缺少逐刀序号，极端网络积压下的逐刀归属仍有限制。

前两击只给武器反馈。第三击确认接触时，标准档另给一次只作用于世界画面的微滚转，设计峰值为 0.72°，150 毫秒内归零。原型通过客户端启动参数 `-Dmyriad.rivetCameraStrength=0` 关闭，`=1` 为标准档。独立世界渲染矩阵承担滚转，HUD 准星、玩家朝向、伤害判定与武器自身的顿挫分别使用原有输入或各自的表现状态。
