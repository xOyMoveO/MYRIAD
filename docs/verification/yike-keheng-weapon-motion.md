# 伊珂与刻衡的持械动作

第一人称用角色自己的方块手臂和皮肤袖口。主手围绕原武器的握把转动，副手空闲时进入画面。第三人称使用同一次服务端动作驱动手臂、肩线和支撑步。两种视角各自保留原本的跟瞄、步态和镜头。玩家选点时可先压低武器；对手从合法确认或真正开始蓄势时看到人物动作。

## 虹轨·伊珂

| 动作 | 主手、副手与脚步 | 释放、收势与中断 |
| --- | --- | --- |
| 免费普攻 | 低托炮身，持械肩短震，保留步态 | 服务端接受免费普攻并产生炮口效果时后坐一次。炮台内拒绝左键时维持原姿势。 |
| 虹标校准 | 炮侧短转腕，副手轻扣 | 每次真实叠层轻扣一次，三层触发时幅度更大。刷新目标上的标记不会重新拨腕。 |
| 稳态屏障 | 稳态就绪时略收炮尾，副手短暂托住炮侧 | 只在有效施法获得护盾时托炮，随即回到主动作。 |
| 虹轨弹 | 起手抬炮、空闲副手托稳；定轨沉肩，游走侧肩 | 真实出膛时分别用普通、重后坐或短回弹。起手打断则随炮身收回。 |
| 折光拒止 | 选点在本人视角轻压炮身，确认时腕部下扣 | 地面预警落下后收手，爆点自行结算。 |
| 定轨炮台 | 按展开进度架稳，副手持续支撑、双脚分开 | 成立后维持跟瞄，每次手动出膛才震肩。退出或耗尽后炮瓣收回。 |
| 游走阵列 | 炮件展开时侧肩托稳，双脚保留行走节奏 | 手动出膛用较短回弹，退出时折回。 |
| 远界重轰 | 合法确认后逐步抬炮，取现有抛物轨迹的起始切向 | 创建实弹时一次重后坐。即使首段飞行被墙挡住，也能看到发射；地面预警与命中各自独立。 |
| 贯虹阵列 | 蓄势架炮；送能时副手支撑，主臂跟随服务端限速炮口 | 持续窗口内保持同一姿势，六次结算共用一次展开。主动二段、打断和到期都收回。 |

## 时律·刻衡

| 动作 | 主手、副手与脚步 | 释放、收势与中断 |
| --- | --- | --- |
| 普攻 | 持刺剑的手短促前送，空闲副手维持平衡 | 服务端接受近战挥击时出手；命中光另由真实目标接触触发。 |
| 刻痕回响 | 第三层短转腕、捻指 | 只在跨施法叠满时触发。目标上的刻度显示前两层。 |
| 恒步 | 进入自己的领域并实际获盾时内收手腕 | 副手短托，冷却中走动不重复。错拍步的护盾保留原本表现。 |
| 迟针 | 起手收腕；针离手时向前点刺 | 起手跟随行动进度；取消只退势，命中不重复点刺。 |
| 错拍步 | 身体朝真实位移方向压低、错肩错步 | 起点残圈留在原地，脚步随角色移动。 |
| 迟界 | 本人选点时悬手，合法确认时压指 | 放下地面预警后收回，领域展开不重复施法。 |
| 随行秒域 | 起手分腕，成立后保留轻微展开姿势 | 自然结束有收圆动作。主动取消或受控中断时散去。 |
| 一秒之外 | 合法选点后两臂抬起一次，展开穹顶 | 后续脉冲属于固定场地。人物落回持剑姿势。 |
| 终刻贯穿 | 两腕合线，起手记录走廊方向；握剑手沿该线蓄势 | 完成才前送，取消则退势。走廊碰撞、伤害和时序沿用原技能。 |

实现入口为各技能的释放、被动触发与起手回调，以及现有的伊珂姿态快照。短动作只给施放者和当时能看见该角色的附近玩家。刻衡蓄势在开始、倍率变化和取消时更新；两次更新之间按已确认的倍率推进。
