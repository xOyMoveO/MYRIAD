# 《万象》对战体验优化与验证记录

基线为主线 `bd99ece3e6b7477760057ada78bf4470da91f0a3`，对应已安装实例的源码。开发分支为 `codex/battle-balance-20261127`。构建目标采用 Minecraft 26.3、Fabric Loader 0.20.1、Fabric API 0.166.2+26.3 和 Java 25。构建产物是 `myriad-0.1.0-no-arms.jar`。此轮留在本地，客户端和服务器同时更新至协议 33 才能交互。HUD 同步的当前法力用了浮点数，原存档格式延续使用浮点数。
