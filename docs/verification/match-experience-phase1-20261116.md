## 已修改的规则

- 发育金币补偿改看双方在线参战角色的**人均本局累计收入**，与现有 TAB 和结算一致，不再读取钱包加旧装备价格。买属性、花掉药品或视野补给不制造经济落后；双方人数不同时仍比较人均，不改成团队总额。
- 累计收入含开局500及实际发放的正常收益；钱包、实际属性支出、实际补给支出分别保存。支出是累计实付额，不是可出售资产估值。尚无正式属性退款机制，本次不新增洗点/出售功能。
- 旧装备出售退款和训练按钮赠金仅补钱包，不重复计为收入；管理员设置钱包也不代表比赛收入。免费训练购买不记实付支出或收入。正常新局重置账本，死亡克隆、持久化和普通重连保留账本。
- 旧附件缺失两个支出字段时为0，不凭当前属性等级追补历史消费，不篡改既有累计收入。旧版已计入的赠金/退款历史无法可靠倒推，不声称会追溯修复；完整新局从新账本开始。
- 保留原金币公式 `min(45%, max(0, (敌方人均收入−己方人均收入)/max(500,敌方人均收入))×0.9)`；经验仍独立比较个人与敌方平均等级，每级差15%、最高45%。不改变击杀赏金、死亡衰减、1.4金币统一换算、补刀比例、角色/技能数值。
- `MatchBalance` 的 DEBUG `farm-catchup` 记录玩家UUID、奖励类型、基础值、双方人数/平均收入、等级差、倍率和补偿后值。金币随后按原调用链执行 `GlobalBalance.goldIncome` 的1.4换算并入钱包；日志中的 `reward` 是此换算之前的值，不冒称最终到账额。默认 INFO 不刷屏，不通过聊天或新网络接口暴露敌方个人数据。
