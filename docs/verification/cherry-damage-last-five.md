# 樱隙首阶伤害审查 · 朔、刻衡、伊珂、铆钉、落霞

本表覆盖五名角色的40个候选技能及普攻。旧值取自 `d219e13`。表中单列的首阶与满阶数值均为零购买、无额外增益的减伤前数值。未标箭头的数值本轮沿用。`力／智` 为单买一点力量或智慧时的首阶减伤前增量。普攻基准为朔、刻衡、伊珂、铆钉65，落霞100。零买配置保留开局500金，另两组分别在本方泉水购买首点力量或智慧，再用相同条件开打。朔与铆钉的近战保留原有±5%浮动，实扣列固定随机种子689、站地充分恢复的普通一斩。

`cherry_hero_damage` 在正式战斗规则下使用服务器模拟参赛玩家，分别学习合法一阶、实际施法或普攻，按每个 tick 读取同一目标的生命变化。靶为与施法者同级、零购买、无被动的天刑，双防45。实扣栏三个数依次为零购买、仅一点力量、仅一点智慧，对确定性伤害核对实扣与减伤前值×100/145。多段行给出固定目标的合计，状态、地形与输入条件写在同一行。“无独立伤害”来自实际登记与处理逻辑。英雄等级为能学习该候选一阶的最低等级，依赖多个技能的场景另列实际组合等级。

固定同样的第一波编制，落霞单独打一记指定技能，再每17 tick松开一支普通蓄力箭。按开场属性生成的两名近战兵各665生命、两名远程兵各455生命。小兵站位固定，测试内没有友方兵线、英雄或塔替玩家输出。起手比较两项E时，普通箭统一在第22 tick开始蓄力，千羽照野的一阶在英雄4级可学，三轮完整结束后第55 tick开始普通拉弓。“清完”是检测到最后一名小兵死亡的模拟 tick，不能等同真人兵线碰面或推进时间。

用 JDK 25 在独立测试世界执行 `./gradlew --offline runGameTestServer -PmyriadGameTests -PgameTestFilter=myriad:cherry_hero_damage`。旧版套件为45组英雄场景和3次清兵，新版为141组英雄场景和3次清兵。完整运行分别生成一个具名 GameTest 的结果。复跑后可在 `build/reports/fabric-gametest.xml` 核对用例名与结果。

服务器在三种构筑下逐段核对。静止、瞄准不变、无打断时，同人可吃满飞羽三箭、千羽三轮与持续领域的全部跳数，移出弹道、离开范围、打断或更换目标都会改变真实结果。这里并未采集有移动对手的真人命中分布。基准数字和属性斜率的回归在 `LastFiveDamageFormulaChecks`，`DamageGrowthChecks` 还用物防100、法防25的猪复核飞羽三段。详细角色段定义及取样时点见[原有段数台账](role-damage-last-five.md)。
