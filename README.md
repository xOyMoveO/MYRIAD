
# 万象 · MYRIAD

我的世界万象mod开发。

多题材角色团队对抗玩法模组，原名《仙凡劫》。未来角色不限于修仙，奇幻、科幻、现代、历史、神话、机械等题材均可按角色定位与机制设计。

中文名：**万象**；英文名：**MYRIAD**。现有地图主题保留。固定功能基线 `8da79ddc329492155cea44f3166c97f0e37d86fc` 的正式阵容为夜影、天刑、焚诀、墨尘、素岚、凌渊、寒泽、青萝、赤霄、云笙、朔、刻衡、伊珂和铆钉，共十四人、112 个独立候选技能。十名旧版角色已退役。支持行动的起手、攻击恢复、自主位移与独立弹体按局部缓时推进；兵线、普通野怪及原版普通／药／光灵箭也已接入。视角、握持、模型、VFX 和听感按用户要求后置统一调整；功能证据与新测试世界交付见 [十三人整合验证](docs/verification/roster13-final28.md)。

本分支正在迁移到仅维护 Minecraft 26.3 正式版 / Fabric Loader 0.20.1 / Fabric API 0.166.2+26.3 / Java 25；#40 以朔「一闪」打通平台与公共链路，保留源码和资源不代表所有角色及地图已验收。内部模组 ID 与资源命名空间为 `myriad`，Java 包为 `com.myriad`，命令为 `/myriad`，构建包为 `myriad-0.1.0.jar`。

2026-11-12 的内部命名迁移不兼容旧身份的存档数据与旧客户端；请先备份，在新世界测试，客户端和服务端同时更新。不要同时加载新旧模组，也不要直接用新包打开唯一一份旧世界。

开发接手请先阅读：[协作开发与内部命名](docs/协作开发与内部命名.md)。

仓库内保留可直接构建的源码与游戏资源。地图存档、个人配置、Gradle 缓存和构建产物不在源码上传范围内；不要把此仓库当作完整的 Minecraft 游戏实例。

Fabric构建、资源校验、隔离启动与GameTest入口见 [Fabric开发说明](docs/fabric/README.md)，角色/资源保留边界与公共入口见 [保留清单](docs/fabric/retention-and-contracts.md)。原协作说明中的26.2/NeoForge运行记录属于历史平台证据，以本分支实际构建配置和Fabric文档为准。
