# 铆钉表现资源

- `hammer.spec.json`、`anchor.spec.json` 是原创立方体结构规格；`tools/assets/generate_rivet_models.py` 调用项目的 BBModel 生成器，再导出手持锤的 Java 模型和技能表现用的实际 UV 面缓存。锤为 9 个、锚为 7 个立方体。共享 128×128 钢灰／黄铜／橡胶／冷青指示材质，均有真实体积。
- `hammer.bbmodel`、`anchor.bbmodel` 内嵌贴图，可编辑；`*_preview.png` 是这些实际立方体的离线等轴预览，已查看。两套模型不放置真实方块，也不改变地图。
- `icon_source.png` 由内置图像生成工具生成，4列×2行；行优先为驻地装甲、破阵节拍、冲击锤、战术锚点、应急撑架、牵引索、固守协议、破城冲击。`icon_export.py` 逐格使用独立测量的完整边框裁切，输出不透明64×64 RGB PNG。原图、原尺寸及放大预览均已查看，八个图标的尺寸／RGB检查通过。
- `tow_release_source.png` 使用内置图像编辑工具保留原牵引索的材质与边框，制作松索时独立的开钩／分离钢索图标，输出 `rivet_tow_cable_2.png`，在真实牵引可取消窗口切换。
- 专属几何入口 `RivetVfx` 使用 13 号主题：实体锚与抬锤模型、双色锚击就绪／恢复指示、挥锤弧、两股钢索、撑架钢板、锁定范围的稀疏球面边界、冲锋箭头、实际运动拖尾及分阶段撞击。高清主层复用项目现有适用纹理，火花仅作有限像素点缀。世界锚／区域根据位置可见性发给观察者，短寿命刷新并去重，不要求其始终看见铆钉本人。
- `rivet_metal.png` 为本角色原创程序化材质。音效使用项目既有 Foley 的钢刃和石质撞击素材，按动作阶段调整音高与音量；没有新增外部录音、配音或生成波形，许可沿用原资源记录。

这些记录证明素材、引用和接线情况；不表示客户端画面、声音听感或运行性能经过实机验收。构建与游戏规则验证由本次专项记录分别记载，未安装正式实例。
