# 归霞反曲弓动作索引

落霞的两种视角共用服务端动作事件。制作分镜时用「技能 ID / 视角 / 事件」定位，例如 `luoxia_sunset_line / third_person / LOCK`。视角使用 `first_person` 或 `third_person`。每轮连射按服务端实际释放次数编号。表内时序以正常倍率下的行动 tick 计，每 20 tick 约一秒，缓时会延长实际用时。

## 弓与箭的挂点

| 挂点 | 模型位置和动作 |
| --- | --- |
| 握点 `handle` | 模型坐标 (8, 8, 8)，两种视角的弓体都围绕这个点变换。持弓手略低于箭台。 |
| 扣弦点 `serving` | `upper_string` 与 `lower_string` 的交点，位于握点的局部 +X 方向。抬弓时在这里放置箭尾，按实收的拉弓进度让箭尾与弦心一起后移。 |
| 箭台 `arrow_shelf_right`、`arrow_shelf_left` | 在握点两侧。握弓手决定箭杆经过哪一侧，箭尖向局部 −X 延伸。第一人称额外露出箭台前方的箭杆。 |
| 空闲、取消和释放 | 空闲弓上无箭。有效松手或技能发射事件到达时撤下手持箭，飞行箭沿服务端弹道出现。取消时撤箭、退弦，空手回位。 |

弓体的待机、起弓、中拉和满拉源模型分别为 [待机](guixia_bow.bbmodel)、[起弓](guixia_bow_pulling_0.bbmodel)、[中拉](guixia_bow_pulling_1.bbmodel)、[满拉](guixia_bow_pulling_2.bbmodel)。模型与同名规格由[归霞弓生成器](../../../tools/assets/generate_luoxia_bow.py)导出。搭箭采用[箭矢源模型](../projectiles/)的网格，弦心位置与握点变换见[共用动作](../../../src/main/java/com/myriad/client/firstperson/LuoxiaBowMotion.java)和[双视角渲染](../../../src/main/java/com/myriad/client/firstperson/LuoxiaBowView.java)。

## 分镜和实射事件

| 技能 ID | 事件、关键帧与时序 | first_person | third_person |
| --- | --- | --- | --- |
| 普攻，按键手势 `PRESS / RELEASE / CANCEL` | `DRAW` 从 0 起弓。普通箭达到 11 工作量可松手。有效 `RELEASE` 一箭，早松 `CANCEL` 并提示蓄力不足。收势可接下一次起弓。 | 主手握住箭台下方，另一只空手取箭扣弦。箭杆保持在准星侧下方。 | 两臂随张力收紧，肩线朝向瞄点。松手回弹，提前松手时收弦。 |
| 追霞续弦 `luoxia_chase_dusk` | 普攻命中敌方角色触发 `CHAIN`，快弓窗口 24 真实 tick。下次 `DRAW` 才搭快箭；1–5 级最低工作量为 10.6、10.2、9.8、9.4、9。一轮仅一次 `RELEASE`。 | 弓臂羽纹闪暖金光；较小侧倾，短拉接轻弹。 | 保持较直肩线、缩短抬肘过程，快箭搭上后才进入持弓姿态。 |
| 凝霞满弓 `luoxia_steady_dusk` | `DRAW` 经过 11 工作量即可射普通箭，达到 20 才亮满弓箭纹并进入慢行。一直按住保持满弓，松手才 `RELEASE`。 | 箭尾贴近拉弦手，达到满弓时换用日纹重箭，松手恢复空弓。 | 前臂撑稳、后肘回收，身体侧转并压低。低于满弓门槛沿用普通箭。 |
| 雁过霞痕 `luoxia_dusk_mark` | 合法输入在同一服务器 tick 内依次 `RELOAD → RELEASE`。没有单独的装填时段。标记由命中事件决定。 | 横弓短促回弹，标记箭从同一次释放出手。 | 肩线侧展，弓横过身前；一次松弦、一个标记箭。 |
| 斜照撤步 `luoxia_slant_step` | `STEP` 跟随实际位移起步、移动、停止；无移动输入则后撤。与已有 `DRAW` 并行，结束时恢复站姿。 | 压低持弓手，保留原箭和张弦进度；空闲撤步时弓上无箭。 | 根据实际滑步方向倾身、前后错腿。遇墙或受控时随位移结束收脚。 |
| 飞羽连弦 `luoxia_feather_burst` | 首箭随提交发射，三个 `RELEASE` 在 0、5、10 tick。两次间隔各自 `RELOAD`；每箭取当时准星。中断停止余下箭。 | 单箭装填、三次清楚的短回弹，逐次减幅，末次收势。 | 三次独立张臂放弦，弓随每次射向调整。 |
| 一点残阳 `luoxia_last_sun` | `WINDUP` 10 tick，允许慢行，提交后单次 `RELEASE`。起手中断走 `CANCEL`。 | 弓身略立，加厚的琥珀箭逐步拉满，一次重回弹。 | 顺步稳定上身、压低肩线，重箭释放时前臂撑住。 |
| 千羽照野 `luoxia_thousand_feathers` | `WINDUP` 7 tick。提交后的第 0、12、24 tick 各一次 `RELEASE`，每次三支箭；两次轮间各自 `RELOAD`。三箭相对中心各偏 −8°、0°、+8°。 | 弓身侧倾，三支箭尾共扣弦心，窄扇形置于视野侧下方。 | 三次张弓对应三轮齐发，第三轮后收臂。 |
| 霞沉一线 `luoxia_sunset_line` | `WINDUP` 17 tick，第 10 tick 进入 `LOCK`，方向固定并沿锁定的三维箭道出现细线预警，至首个障碍截断，第 17 tick 单次 `RELEASE`。中断撤箭。 | 厚箭压在箭台上，锁线后随已确认方向稳住弓，单次重回弹。 | 原地沉肩、前臂沿锁线停稳，释放后还原站姿。 |

即时箭的动作可通过抬肩和回弹读出。剪辑或制作额外关键帧时，装箭与释放允许落在同一服务器 tick，连射与扇射的释放帧均跟随实际事件。技能代码位于[落霞角色目录](../../../src/main/java/com/myriad/character/skills/luoxia/)，同步和取消的事件名称见[姿态协议](../../../src/main/java/com/myriad/network/LuoxiaBowPosePayload.java)。
